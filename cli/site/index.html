下载安装包 ↓

需要 Node.js 22.12 或更高版本，以及已安装的 Codex 或 Claude Code。命令会安装 CLI、设置 MCP 并检查授权；已有有效授权会直接复用。

装好之后，只需要这一句

zhicui connect

直接下载视频

zhicui download "视频链接"

拿到地址后直接下载，显示传输进度。

提取原声音频

zhicui audio "视频链接"

保存 MP3，包含人声与配乐，无需先提取文稿。

只获取下载入口

zhicui resolve "视频链接"

不先下载整个视频，也不等待文稿提取。

连接后，在 Agent 中重新连接知萃 MCP。B站分离音视频可使用资料页合并下载。

先同步，再交给 AI 分析

zhicui sync --platform douyin --mode like --limit 200

自动连接已安装客户端，后台读取最近喜欢。首页和 Agent 显示同一份进度，中断后用任务 ID 继续。

zhicui sync resume <run_id>

已有授权自动续期；需要平台扫码或验证时会提示。清单时间是首次同步日期，不是平台精确点赞时间。
