给 Agent 一个密钥，
后续直接用。

在知萃生成密钥，复制给 Codex 或 Claude Code。连接会安全保存，后续导入视频、提取文稿、下载与问答直接复用。

三步，完成首次接入

  1. 生成 Agent 密钥

    打开知萃「Agent 接入」，点击「生成 Agent 密钥」，默认包含当前服务支持的日常权限。

  2. 复制给 Agent

    点击「复制给 Agent」，把完整内容粘贴给正在使用的 Codex 或 Claude Code。Agent 会完成安装与连接。

  3. 直接交代任务

    例如：“用知萃提取这个视频，并保存到我的资料库。”后续继续复用连接；本机操作时保持知萃已打开并登录同一账号。

去生成 Agent 密钥

密钥在有效使用时自动续期，连续一年未使用才失效。可随时在知萃停用；平台登录或验证仍按实际需要提示。已有只读连接的权限不会自动改变。

连接后，让 Agent 帮你处理资料

导入和提取

把支持平台的公开视频链接保存到资料库，提取文稿，客户端也能看到。

下载和问答

下载可获取的视频或原声音频，围绕已有资料继续提问。

可用功能以当前服务和客户端为准。导入、同步和写入仅在你或 Agent 明确调用时发生。

通过标准输入接收密钥

zhicui connect --pat-stdin --client codex --non-interactive --json

由 Agent 将密钥通过无回显的标准输入传给此命令。不要把密钥写进命令参数、配置文件或日志；CLI 验证后保存到系统安全存储。

设备授权与连接诊断

如需改用设备授权、固定期限 PAT 或查看连接诊断，可打开知萃 Agent 接入中的「高级设置」。设备授权使用 zhicui auth login，只在你选择此方式时发起。
