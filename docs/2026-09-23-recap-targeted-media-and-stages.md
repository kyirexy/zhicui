# 每日回顾播放地址与处理耗时修复

## 已确认的线上原因

2026-09-23 11:20:21–11:21:39 的文稿批次共 23 条，22 条失败、1 条无语音。服务端连接器日志确认这 22 条未携带桌面临时播放地址，退回 `/api/v1/media/<id>`；上游因账号验证返回 403（`argus_uifid_missing`），连接器对外转成 404。不是任务调度死锁，也不能据此判断视频无音频或已删除。

唯一实际取得媒体的条目下载提音频耗时约 699 ms，ASR 耗时约 46 秒，结果为空。旧界面“处理中”把下载和语音转写混在一起，无法区分耗时来源。

## 修改

- 桌面 1.1.14 新增受校验的指定视频读取请求，直接在已登录的隔离浏览器里打开目标详情，最多三路并发，只采集匹配 ID 的官方响应/页面内嵌视频地址。跳过收藏、喜欢列表扫描，完成后关闭本次创建的标签。定向结果永远不是账号完整列表，不用于来源清理或改写首次同步日期。
- 首页按桌面版本协商；旧版仍可列表探测，未覆盖明确提示升级。桌面已确认无地址的条目保留待重试，不再提交被拒绝的备用通道。部分就绪仍进入 AI，并在总结中说明覆盖范围。
- 主动今日分析同步显示浏览器窗口。新隔离会话优先系统默认 Chrome/Edge；已有会话保留原浏览器，避免破坏登录。防止后台计时及遮挡节流，Edge 不再误报 Chrome。
- 定向读取首次显示真实详情页；明确遇到登录/验证码时前置对应页、显示操作提示并有界等待，支持取消。正常单条读取窗口 12 秒，验证等待最多 60 秒。窗口焦点严格限当前账号当前会话。
- 临时媒体缓存按身份切换清空，仅保存在内存，不把前一账号的地址用于后一账号。
- 后端和首页区分下载音频、语音转写、AI 整理；聚合任务同时重算阶段数量。失败原因以用户能理解的中文提示展示，日志只记来源渠道、状态和耗时，不记录签名媒体地址。
- 完整音频解码采样全部为零时提前跳过 ASR；轻声或音乐不按静音误判。下载完成复查取消，避免继续发送付费 ASR。
