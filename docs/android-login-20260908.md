# 安卓登录体验与会话保留

## 变更

- 登录页去掉多层套框与大面积深蓝主色，改为简洁单列、浅蓝主按钮。
- 保留手机扫描已登录电脑二维码的路径；账号登录提供持续可见标签、密码显示/隐藏与自动填充语义。
- 设置所有分类顶部显示当前账号和退出入口；退出需确认，不执行账号注销或删除云端资料。
- 本地持久保存现有 JWT 和最小账号缓存（不保存密码、不缓存管理权限或 Agent 绑定），启动恢复并在线复核。
- 短暂网络失败不清除会话；过期或当前 token 收到 401 时清除；会话代次阻止退出/切换账号后旧异步结果写回。
- 扫码相机的全局透明 CSS 移到全局样式，兼容 Webpack 的 CSS Module 纯选择器规则。
- 手机取消扫码时同步作废 claim/token 请求；正常扫码成功关闭相机不会取消后续电脑确认。
- 网页向桌面交接登录时保留等待/错误/成功页面，失败可重试，不提前跳首页。
- 头像保存使用仅更新当前账号资料的接口，不再调用接受登录会话；退出后的迟到头像响应不能重新写回 token。
