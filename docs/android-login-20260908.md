# 安卓登录体验与会话保留

## 变更

- 登录页去掉多层套框与大面积深蓝主色，改为简洁单列、浅蓝主按钮。
- 保留手机扫描已登录电脑二维码的路径；账号登录提供持续可见标签、密码显示/隐藏与自动填充语义。
- 设置所有分类顶部显示当前账号和退出入口；退出需确认，不执行账号注销或删除云端资料。
- 本地持久保存现有 JWT 和最小账号缓存（不保存密码、不缓存管理权限或 Agent 绑定），启动恢复并在线复核。
- 短暂网络失败不清除会话；过期或当前 token 收到 401 时清除；会话代次阻止退出/切换账号后旧异步结果写回。
- 扫码相机的全局透明 CSS 移到全局样式，兼容 Webpack 的 CSS Module 纯选择器规则。
- 手机取消扫码时同步作废 claim/token 请求；正常扫码成功关闭相机不会取消后续电脑确认。
- 网页向桌面交接登录时保留等待/错误/成功页面，失败可重试，不提前跳首页。
- 头像保存使用仅更新当前账号资料的接口，不再调用接受登录会话；退出后的迟到头像响应不能重新写回 token。

## 验证边界

- 浏览器开发页 390px 无横向溢出；空表单提示、密码显示/隐藏、注册切换正常。
- 沿用项目 Node test 和 TypeScript 检查，没有引入测试框架。
- 最终六模块 39 项测试通过，TypeScript 无错误，`git diff --check` 通过。
- 设置与会话浏览器测试使用隔离模拟账号，不创建或修改生产账号。
- 设置 320/390px：44px 退出入口首屏可见，所有分类有且仅有一个入口；取消保留凭据、焦点恢复；连续三次打开/Escape 无残留弹层，确认退出及刷新清理成功，运行时错误为 0。
- 真实 AuthProvider 的浏览器 mock 集成 6/6：表单登录、刷新、断网、503、当前 401、退出后迟到 `/me` 均符合预期。所有 `/api/*` 拦截，外部请求阻断。证据 `.tmp/auth-persistence-20260908/results.json`。
- JWT 当前有效期为 30 天，不是永久免登录，也没有本轮新增的自动续期。
- 退出清理当前设备本地会话，不是服务器全设备 JWT 撤销。
- 安卓发行版本与安装验证结果在构建完成后补充，不把浏览器视口模拟当作真机测试。
