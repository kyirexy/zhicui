# 2026-10-09 登录恢复可靠性修复

目标版本：Web 1.1.17 / Windows beta 1.1.20；CLI 继续使用 1.0.18。

## 已复现与修复

- 渲染器遗留退出标记会跳过恢复并主动注销主进程。桌面改以加密会话为事实来源，退出意图绑定 sid；条件退出在主进程再次检查 sid 和代次。旧 preload 没有条件退出能力时不发送无保护的补偿注销。Web 离线退出保护保留。
- 刷新已提交但响应丢失，离线超过原 10 分钟回执窗口后误退出。登录回执延长到当前后继会话到期，每个 owner 仅保留最新回执；重试签发有效访问令牌，不延长会话、不重复轮换。不同请求重放、撤销、禁用及后继凭据再次轮换均拒绝。
- 迁移响应丢失后源 JWT 到期，允许签名有效的原 token + 原 request_id 领取已有有效回执；绝不允许过期 token 新建会话。
- 网页交接改为等待主进程加密保存及本机身份绑定后才提示成功；保存暂时失败重试原凭据，不重新轮询已消费票据。
- 主进程串行处理恢复、采用和退出，合并相同凭据的并发采用；旧请求不能覆盖新登录或主动退出。
