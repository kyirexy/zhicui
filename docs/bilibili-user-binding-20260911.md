# B站个人云端绑定验收 — 2026-09-11

用户要求：CLI 由用户本人绑定平台账号，不能使用管理员共用账号。知萃登录与平台授权分开；未绑定平台仍能查询已保存资料。

## 实现

- 网页 `/connections/bilibili` 登录后显示本人官方二维码。CLI 提供 `platform bind/status/poll/disconnect bilibili`，bind 返回网页地址，无需桌面客户端。
- 服务端 `bilibili_account_bindings` 每位知萃用户一行，QR challenge 和 Cookie 使用 ENCRYPTION_KEY 加密；不接受外部 Cookie、密码或 user_id，不向 Action 结果返回二维码秘密。
- 所有查询、扫码完成、断开按认证用户隔离。PostgreSQL 行锁串行化扫码完成与断开，generation 阻止旧同步请求影响换绑后的账号。
- B站投稿目录改用当前用户授权的官方 WBI 分页 API。无绑定、身份不匹配、过期、风控直接停止，禁止回退到 yutto/yt-dlp 共用会话。全量成功必须有可核对的投稿数；不完整结果不得把旧作品标记删除。
- 目录管理员测试验证管理员自己的个人绑定；用户同步仍只读取自己的绑定。全局健康探针检查加密及官方 WBI 协议，发布资格继续要求近期真实目录验收。
- 网页轮询每 3 秒一次，接口限流；平台拒绝也保留轮询间隔。跨账号入口、取消、卸载页面停止轮询。
- 本地桌面点赞/收藏同步保持独立，不将桌面 Cookie 自动上传云端。
