# 视频准备使用流程简化（2026-09-28）

## 行为

- CLI 1.0.5 支持 `library prepare '<链接或分享文字>' --connect --timeout 10m --jsonl`。只在缺少有效知萃授权/必要权限且用户显式传入 `--connect` 时申请设备授权；浏览器确认后接续同一任务。原 PAT 不会自动扩权。
- 默认目录为当前项目 `zhicui-media/<服务、profile、链接的哈希>`；再次执行相同命令自动核对并复用原进度。显式 `--output` 保持不覆盖、显式 `--resume` 的行为。
- 中文进度包含识别、文稿、下载字节数。错误给出恢复命令和结构化 `resume_argv`，平台限制与知萃权限不足分开说明。没有添加平台风控重试。
- 授权轮询允许短暂 502/503/504 后继续等待，保持原授权码；授权完成事件在复合流程中不是终态，素材完成或失败才结束事件流。
- 网页 Agent 接入区分已有资料问答与视频素材准备；主入口为给 Agent 的接入提示词，手动 CLI 命令折叠。视频目的明确请求读取和整理资料权限。授权页说明无需复制令牌。
- 素材准备完成仍不等同于 Hypit 复刻完成；本次未修改 Hypit 编辑器或启动视频模型生成。
