# 并发文稿与首页昨日回顾

日期：2026-09-10。实施 worktree：`codex/home-sync-preview-20260909`，基于已上线的 `10da82a`，未混入主工作区其他改动。

## 行为

- 文稿沿用真实线程池并发，生产新批次计划将 ASR 配置从 2 调至 4；进度按实际 active、成功和排队条数展示，终态不再显示“正在”。
- 同任务短事务/数据库行锁保护取消与进度写入，重启补齐“条目全部完成但批任务未汇总”的终态。
- 首页同步区下增加“昨日回顾”，桌面与移动端共用。点击后批量补齐文稿，复用已就绪文稿，再生成可继续问答的 AI 会话。重复点击、断线、账号切换均保护任务标识，避免重复提交已发出的 AI 请求。
- 统计口径为各点赞/收藏来源在知萃的首次同步时间；不推断平台真实操作时间，不按视频发布时间或最近编辑时间排序。首次历史导入及无法确认的旧记录分别提示。
- 同一视频喜欢与收藏合并显示。只读接口按用户、时区和当地日历日期过滤，禁止缓存；最多解析 100 条，页面明确范围。
- B站来源台账与新 Note 同事务；旧模式没有可靠首次日期时不回填。补全文稿保留原来源分类、每分类排序、水位、首次时间和已有文稿。
