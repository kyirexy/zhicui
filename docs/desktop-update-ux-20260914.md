# 客户端更新体验 · 2026-09-14

本轮只调整知萃更新相关界面与状态处理，继承现有桌面蓝色操作、知萃图标、浅色/深色实色表面，不调整全站设计体系。对标抖音安装更新的清晰步骤和克制层级，不使用其标识。

## 任务与界面

发现新版本、后台下载不打断当前任务。左侧在有新版本、错误或重启状态时显示更新入口，点击后打开稳定挂载的原生 dialog；设置的“版本更新”使用同一组件、同一状态。标题直接说明发生了什么，版本行只展示当前/新版本，主要按钮优先表达下一步。隐藏渠道、构建号、校验证书/网络请求等底层信息。

下载中展示线性进度及“可以继续使用”；下载验证完成且原生允许安装时，主操作为“重启并更新”。重启只由用户主动点击触发，提醒先保存当前输入。无法自动安装时如实显示“本次更新需要手动安装”，不把未签名包宣称为自动更新已就绪，也不承诺一次手动安装后所有未来更新都能自动应用。

网页功能更新采用右下角非阻断提示“页面有新功能”，说明保存输入后刷新即可、不需要安装。客户端有新版本、正在下载或正在重启时不同时展示网页提示。

已实现组件为 `DesktopUpdateCard`（状态、版本、最多四条更新内容及操作）、`DesktopSidebarUpdate`（侧栏入口与常驻 dialog）和 `WebBuildUpdatePrompt`（网页更新提示）。前两者共用 `useDesktopUpdate` 控制器；关闭、Esc、点击遮罩和切换路由均可收起弹窗，不手动移除 React 管理的 DOM。

默认分流依据实际运行环境和更新能力：已登录桌面客户端才显示网页构建提醒，启动 12 秒后检查、每 30 分钟复查，回到窗口时检查至少间隔 60 秒；仅网页构建变化时由用户点“刷新更新”，关闭后本会话不再提醒同一构建。客户端更新优先显示在侧栏，由原生状态决定下载或重启；当前未签名 Beta 始终走手动安装分支。

## 交互与数据边界

- 共用更新控制器，侧栏和设置同时点击只发一次检查、下载或安装请求；晚到的初始查询/IPC返回不覆盖已经推送的新状态。
- 自动重启须满足 native `downloaded`、`canInstall: true`，且 `downloadedVersion` 与当前新目标一致。原生 `installing` 期间禁用再次安装；返回错误或不支持时释放操作，不永久显示“正在重启”。
- Windows 备用下载只读当前安装渠道的公共清单；严格校验 luxai.cn、平台、架构、版本化文件名、版本大于已安装、元数据格式，不使用 legacy/latest 或内置旧版兜底。点击下载前再次刷新清单，失败/回退不打开包。
- “安装包已打开”仅说明打开了浏览器下载；不假装下载完成。普通连续点击去重，未开始下载时用户可显式点击“重新下载”。
- Android 保留系统安装器确认，文案改为“下载并安装”，隐藏渠道和 build；并发版本检查共享一次请求，不为解析 availability 二次请求。
- 原生签名验证、下载校验、静默安装与卸载器由 desktop 更新实现负责。前端测试不代替真实安装验收。

## 视觉与无障碍

实色表面、8–14 px 圆角、品牌图标、单一蓝色主操作；没有营销插画、装饰渐变或技术状态墙。操作目标至少 44 px；明确焦点环、关闭按钮名称、下载 progressbar、减少动画偏好。窄屏按钮纵向排列，dialog 控制最大高度并可滚动，保留安全区。

更新卡片使用现有表面与文字变量，桌面字体继承 Segoe UI 系列；标题 22 px、说明与主按钮 14 px。主按钮固定蓝底白字（#335bea，悬停 #274aca），次按钮随主题使用次级表面与文字；暗色桌面卡片为 #171b22，次按钮为 #16191f 配 #a8b0b9。禁用态透明度 0.65，可用主按钮保持 1；焦点环 2 px，背景与进度变换为 160 ms，减少动画偏好下取消旋转和过渡。

弹窗宽度为 `min(480px, 100vw - 32px)`，最大高度为 `min(88dvh, 740px)`，超出可滚动。640 px 及以下卡片内边距缩为 22 px／18 px、标题 20 px、图标 44 px，操作纵向排列且底部计入安全区。网页提醒最大宽度 340 px，距底部 84 px 加安全区，桌面距右 24 px、窄屏 16 px，留出反馈浮钮位置。

## Windows 安装程序

真实 NSIS 首屏使用知萃图标、中文大标题和安装位置，默认当前用户安装，首屏可改专用安装目录；覆盖安装沿用原有路径。新增写入权限及可用空间检查，提权后的内部进程不重复展示首屏。完成页可直接打开知萃。保留 electron-builder 的官方安装、提权、卸载、快捷方式与静默启动流程；不删除 AppData，不迁移账号资料。

真实安装程序已通过 electron-builder / NSIS 编译；未取得实际 NSIS 窗口截图，也未执行真实安装、升级或回滚验收，编译通过不代表这些验收通过。本轮构建目标为未签名 Beta，仍需手动安装。原生静默更新能力仅在有发布者签名且通过发行验收的 Stable 包开启，Beta 提供经清单确认的固定版本安装包。记录更新时最终产物仍在构建，生产发布结果待发布记录确认。
