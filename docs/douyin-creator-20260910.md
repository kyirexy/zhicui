# 抖音博主同步接通

日期：2026-09-10。基于线上 `c33515b` 的隔离工作树 `codex/douyin-creator-20260910`。

## 根因与修复

- 线上抖音平台从未完成博主连接验证，因此入口禁用。旧 sidecar 虽声明 `creator_catalog`，但实际没有四个博主路由。
- 旧主服务对所有博主识别错误生成占位姓名，近期作品又回退到 `auto-collect mode=post`；该旧执行器忽略目标 URL，只读取当前账号自己的作品。已删除这两种错误回退。
- 新增独立主页、近期、分页目录和取消接口及版本握手。目标主页 ID 与每条作品作者必须匹配；所有响应均按公开元数据白名单输出，没有 Cookie、媒体 URL 或持久媒体下载。
- 主页资料接口受限时，通过归属已验证的公开作品读取真实作者名。支持整段抖音分享文案、`v.douyin.com` 短链和 `www.iesdouyin.com/share/user/` 落地页，最终只保存规范主页。
- 分页绑定用户作用域、博主、范围与游标；重复页去重，同页重试复用响应，游标循环和空异常响应不会伪装成完整成功。近期跳过平台置顶项和图文，以普通视频列表选取 20/50/100 条。
- 近期、全量都把公开元数据保存到知萃的博主目录，不混入本人喜欢/收藏/作品。转写直接使用所选博主的资料；重复转写复用现有文稿。
- 抖音全量刷新采用增量保留：未出现在本次公开目录中的历史条目不会因此变成不可见；用户主动移除状态保持原样。
- 管理连接测试必须真实验证主页及作品读取，并记录成功测试审计；只访问健康接口不再开放平台。
