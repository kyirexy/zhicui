# 抖音列表读取失败的恢复引导

日期：2026-09-14。基于当前生产提交 `084a9e405f64843c67916295ba4fdcd79c1b9f21` 的独立工作树实现，没有把主目录未发布的旧同步逻辑整批合入。

## 原因和改动

“没有读取到抖音官方分类首屏”表示尚未取得目标分类的可信列表开头，不等于已经确认账号触发验证码。可能是页面没有加载完成、登录/验证提示挡住列表，或列表请求没有返回。

旧客户端只有“没选上标签”时会显示浏览器；标签已选中但首屏未到达时，后台最小化窗口会在报错后被关闭，用户没有机会操作。

- 首屏未返回时先给正常网络 10 秒，随后前置官方窗口，保留本轮请求监听等待用户 120 秒。只有官方可信首屏实际返回后才继续，后页或截图卡片不能替代首屏。
- 新增当前账号已有窗口的聚焦入口，不创建新会话或额外采集。重试显式传入 `interactive: true`，直接显示浏览器。
- 资料页和同步弹窗显示三步引导：确认本人主页、选择对应分类并按官方提示操作、等待列表开头显示。明确提供显示窗口、取消、原分类原数量重试按钮。
- 兼容 1.1.4 旧中文错误与等待事件；喜欢失败后，收藏成功或后台文稿进度不能覆盖喜欢的待处理提示。
- 账号会话已保存和列表读取成功分别展示；不把未读取成功写成“连接正常、可以同步”。
- 登录异常可重试；账号切换后清除旧引导，迟到的窗口/登录结果不覆盖新账号或新一轮同步。显示窗口请求未返回时仍能取消。

增量保存、去重、历史资料保留、严格来源顺序和本人账号校验均保留。网页引导兼容旧客户端，但自动前置、等待恢复和聚焦入口需要 Windows 1.1.5 新二进制。
