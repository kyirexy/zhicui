# 首页显示 CLI / Agent 同步结果（2026-10-02）

客户端首页新增紧凑的同步动态区。桌面采集事件显示连接、读取、验证和等待保存阶段；云端同步记录显示逐条保存计数及最终新增、复用、失败、跳过数量。清单读取成功不视为保存成功，部分失败不显示为全部完成。

登录后的共享观察器只读取已有同步任务，前台空闲每 10 秒检查一次，保存中每 2 秒检查一次，窗口重新激活立即检查。没有新增自动同步或重试行为。记录变化后统一失效首页、资料库、每日回顾的缓存；网络异常保留已有结果，切换账号取消旧请求并隔离旧结果。

首页抖音和 B 站的分类均改为“喜欢、收藏、作品／导入”，默认优先喜欢。已有用户主动选择保持不变；没有喜欢时展示实际有内容的来源。

修复 Agent 清单只写入 Note 与来源台账、没有进入客户端目录的问题。抖音目录兼容读取这类已保存清单，已有完整桌面快照仍优先；B 站目录合并台账中的喜欢、收藏关系，并显示未提取文稿的 Agent 清单。此投影不更改首次发现日期，不伪造来源排名、封面、文稿或就绪状态，不触发下载、ASR 或 LLM 请求。旧 CLI 1.0.12 兼容，不需要更新原生客户端或令牌权限。

- 前端首页、回顾、同步相关 Node 测试 143 项通过，覆盖外部进度、去重刷新、迟到响应、账号切换、断网保留和隐藏页面暂停。
- 后端 Agent 清单、同步持久化、抖音目录、平台导入与同步路由测试 102 项通过，覆盖目录可见、用户／来源隔离、双分类和保存过程可观察。
- TypeScript 和 Next.js 生产构建通过，生成 44 个页面。
- 隔离浏览器使用真实生产构建与受控 API／桌面桥夹具，验证采集 → 保存 20/50 → 完成 50 条、喜欢数量 451 → 501、部分失败、分类顺序以及 1440/1024 像素布局；无页面运行时错误。不将夹具验证描述成真实平台采集。
