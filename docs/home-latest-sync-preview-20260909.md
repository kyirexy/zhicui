- 基于当前正式版 `ca699d811c9589125b09e58a4f24b92f64e04db9` 的独立 worktree 整理；不直接发布主工作区其他未提交修改。
- 保留线上已发布的同步快照、分批偏移、顺序可靠性、旧请求拦截和登录会话保护。复用 `source_synced_ats/source_ranks`，不引入第二套来源元数据。
