# 首页视频操作验收（2026-09-15）

本次只扩展首页已有卡片：昨日回顾和抖音、B站平台预览共用视频身份与显示偏好，保留现有蓝色主题、信息顺序和原生入口。桌面右键或点击更多按钮可加入知萃知识库、从首页隐藏；拖动卡片时，页面底部显示明显的隐藏区域。移动端提供 44px 更多按钮和长按菜单，菜单在视口内显示。

隐藏操作只有在服务器确认后才移除首页卡片，可通过提示中的“撤销”恢复。隐藏不删除视频资料、同步记录或知识库条目。同一视频在昨日回顾和平台区同步更新，平台预览在过滤后按原顺序展示前三条。首次读取显示偏好前不展示卡片，读取失败保留重试入口，不以空偏好冒充成功。

接口使用当前登录账号的 `/api/home/video-preferences` 和 `/api/home/knowledge`，操作身份为 `platform + video_id`，B站不使用笔记 ID。控制器在发送前后验证账号与令牌；每条视频的并发操作合并，旧读取不能覆盖刚写入的结果。首次加载及后续同步分类事件会保留用户本次同步分类，旧缓存、晚返回的其他分类和旧账号事件不能覆盖。

菜单使用稳定挂载的 React 元素，不使用 body portal 或移动 React DOM。支持 Escape、方向键与焦点返回。首页文稿准备、显示偏好保存期间会登记网页更新忙碌状态。
