# 首页真实案例管理

## 定位与首页展示

首页的「仓鼠型」指爱收藏教程、观点和资料的习惯。文案围绕「先收藏 → 找到重点 → 留下知识和行动」展开，不把它当成心理学人格分类，也不承诺所有收藏会自动被处理。

真实案例区读取后台已发布内容，按行业筛选、切换案例，展示录屏或动图、遇到的问题、实际操作和最后的成果。没有已发布案例时，继续展示此前已核对的 B 站原视频与实际知识卡片节选；不会自动生成客户姓名、评价或行业背书。

## 管理员操作

1. 使用管理员账号登录，进入「首页案例」。
2. 新增案例，填写行业、标题和一句话简介。按实际情况填写展示称呼、职业、问题、操作过程、产出、来源名称和公开链接。允许使用已获同意的匿名称呼。
3. 选择实际使用的 MP4 视频或 GIF 动图上传；MP4 不超过 100 MiB，GIF 不超过 20 MiB。MP4 使用 H.264 编码，录屏建议 20–45 秒、720p 或 1080p，并用清晰字幕说明操作。不要录入账号密码、私有聊天或未获同意的个人信息。
4. 先保存草稿，在管理端播放预览，核对文本和素材。确认是实际使用记录且拥有展示授权后发布。
5. 打开首页「真实案例」检查。发布内容无需重新构建网站；刷新首页或重新切回首页标签页会读取最新列表。
6. 可以调整顺序、编辑内容、替换媒体、下架或删除。修改或替换已发布案例会回到草稿，需要再次核对并发布。下架后，公开列表和媒体地址均不再可访问；已被访问者保存的文件无法撤回。

视频由访客手动播放，支持手机内联和全屏观看。GIF 先展示静态首帧，点击后才加载并播放，支持停止；离开画面或切换标签页会停止播放。网络异常时仍能阅读案例文字。

## 收集真实案例的方式

先邀请已经使用产品的人各提供一个具体过程，逐步覆盖学习、内容创作、设计、开发等场景。行业标签以提交的实际案例为准。一次只讲一个问题，不用「效率提升 10 倍」等没有依据的数据。

推荐访谈提纲：原来收藏了什么、当时想解决什么问题、在知萃中实际选了哪些内容/问了什么、最后留下什么、哪一步仍需要人工核对。把对方确认过的录屏、称呼、文字和授权一起存档，再发布到首页。

短视频宣发可直接从获授权的案例中剪取：前 3 秒展示具体困扰，中间演示一次真实操作，最后展示知识卡片或行动计划，并引导到首页对应案例区。面向爱收藏的人强调「让已有收藏派上用场」，避免用焦虑催促他们囤更多内容。

## 存储与访问

案例文字和发布状态保存在应用数据库中。上传文件与自动生成的首帧保存在 `CASE_MEDIA_DIR`；生产目录独立于每次部署的代码目录。草稿预览需要管理员 Bearer 鉴权，公开接口只返回已发布内容。发布、编辑、上传、下架和删除都会留下管理审计记录。

存储路径、容量保护、备份和发布检查见 [媒体运维说明](../deploy/CASE-MEDIA-RUNBOOK.md)。素材不会提交进 Git，不会放进客户端安装包。
