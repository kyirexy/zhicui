# 官网演示切换稳定性修复

## 问题与处理

- 三个步骤原先按条件卸载，内容超过 min-height 后各自高度不同；首屏居中布局会随卡片高度重新定位。
- 三个轻量静态面板改为共享同一 CSS Grid 单元格，由最高内容自然撑开。没有写死高度、裁剪正文或新增高度动画。
- 非当前面板使用 visibility、aria-hidden 和 inert，保留布局但不接受点击、键盘焦点或读屏访问。
- 原文依据放入问答面板，切换及播放保留展开状态，避免收起时再次改变布局。
