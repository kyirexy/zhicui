# 2026-10-19 封面与媒体代理恢复

## 线上事实

巡检当前运行提交 `efe1ed7`：滚动 7 日有 281 次抖音封面 503、9 次媒体 502（8 次普通资料库、1 次 Agent 直连）。数字是请求数，不是用户数或作品数。封面 503 是所有原图候选失败后的占位响应，不能当作原图加载成功。

授权后只读复核最近 3 个失败封面和 1 个失败媒体，使用原绑定的回环连接器接口，均返回 404（约 1–4 秒）。这 3 个封面没有当前本机快照封面；另取最近一个检查旧目录归档，也未找到该封面。媒体样本存在旧目录归档，但公开解析仍返回 `VideoMetadataUnavailableError`。这证明旧资料中的地址不能保证当前可读；不足以断言作品已删除，也不能承诺通过重试恢复所有原片。

检查未输出签名 URL、scope、Cookie、用户身份或正文，未更新生产目录、凭据或数据。公开读取和连接器读取只用于有限样本定位。

## 修复

- 封面优先使用已有成功缓存和已有公开地址；连接器明确返回 404/410 时，通过原作品 ID 重新读取公开元数据，仅接受平台和作品 ID 同时一致的结果。导入资料的空封面也可以执行这一恢复。
- 公共 CDN 重定向逐跳校验白名单，最多 3 次；回环连接器仍禁止重定向，绑定 scope 不会传到公共 CDN。
- 临时网络/上游故障最多重试 1 次。失败封面保留 503，并给出 30 秒冷却和安全原因码，避免刷新列表反复请求已失效来源。
- 普通抖音资料库媒体补齐同作品公开恢复；原先仅导入 Note 路由具备回退。401/403/429 不通过公开回退绕过平台登录或验证。恢复后的 Range 请求保留，416 正确传递为范围协商结果。
- 公开元数据恢复按绑定 scope 隔离；成功缓存 180 秒，失败缓存 60 秒，最多 512 项、2 条并发。解析器已有连接/读取超时，并新增 20 秒跨重定向预算和分块读取期限检查。
- 失败日志只记录阶段、来源类别、安全原因枚举及 HTTP 状态；不记录 URL、scope、异常字符串或供应商正文。流传输中断也留下安全原因，并关闭连接。
