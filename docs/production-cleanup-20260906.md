## 视觉模型核查

- 当前线上发布的免费模型：`deepseek-ai/DeepSeek-V4-Flash`，`supports_images=false`。
- 通过现有平台模型配置发送一张程序生成的双色测试图，不包含任何用户资料；实际图片请求返回 `BadRequestError / HTTP 400`。该结果不等于已查明模型本身没有视觉能力，也可能是当前接口或参数不兼容，不能据此直接开启图片标记。
- 后续查询现有服务的模型目录，发现 `Qwen/Qwen3-VL-8B-Instruct`。复用同一服务与密钥真实调用后，正确返回测试图左侧 cyan、右侧 red，无需另购图片解析服务。

- 现有图片问答代码会直接以 `image_url` 消息传给所选模型。单独“详细解析方案”的发布能力与一次图片问答不同，不能把两者混同为已经上线。
