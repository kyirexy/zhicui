## 已完成修复

- 提取流程按登录账号隔离状态。退出或换号时清理预览、转写和结果，终止旧请求；旧 SSE 回调和迟到响应不能写回新账号或覆盖新任务。
- 创作工坊补齐“获取估价 → 展示报价 → 明确确认”的流程。确认绑定作品脚本和报价，脚本或报价变化后必须重新确认；估价失败可重试。执行端使用已确认的报价，不在确认后替换报价。
- 创作工坊成品播放和下载通过现有会话请求机制鉴权，兼容静态客户端的 API 地址；增加媒体大小限制、取消、卸载清理和对象 URL 回收。首次提交失败可见，旧轮询响应不能切回已离开的任务。
- 密码重置通过账号凭证版本撤销旧登录凭证，并覆盖刷新、迁移、扫码和 Agent 授权路径；调整用户与会话锁顺序，在独立活动日志写入前释放登录事务锁。
- 计划任务修改重新读取并锁定当前记录，保留完成时间和历史；同一任务 ID 被新内容、不同日期或排期复用时，不继承旧任务的完成状态。
- 媒体代理增加有界恢复、失败冷却和脱敏诊断。恢复按账号及作品隔离，并校验同一作品身份；保留可信地址、重定向检查、Range 状态和流关闭处理。

## 发布后补齐

### 首次发布闸门发现并回滚

Jenkins #321（提交 `540d48ef4810cdd819e8cc52ad3a54a39694261a`）构建、健康和权限边界检查通过，但新版 Android 安装包下载返回 403，部署已自动回滚。根因为 `umask 027` 与 `rsync --no-perms` 使新文件落为 `0640`，Nginx 用户不可读；原 `--chmod` 参数不能覆盖该组合的掩码。

发布脚本新增对清单选中安装包的读取权限修复：拒绝符号链接，创建同目录临时文件、设置 `0644`、比较内容后原子替换，保留原共享目录权限；适用于 Jenkins 与人工发布账号切换的场景。安装包 SHA-256 及公网完整下载闸门继续保留，修复后重新部署。

Linux 临时目录实测已复现原 `0640` 问题，并通过跨发布账号修复、SHA-256 一致、Nginx 用户可读、重复执行不改变 inode/内容/所有者、拒绝符号链接和空文件等检查；目录 `2775` 保持不变，临时目录已清理。
