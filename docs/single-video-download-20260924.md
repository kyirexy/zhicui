# 单条解析恢复与视频下载（2026-09-24）

## 生产问题

实际失败作品为 `7616369026764347109`，原始分享链接为 `https://v.douyin.com/JUV4bfM5wBU/`。
正式日志显示绑定下载器的作品缓存与媒体接口均返回 404，旧页面却提示“已通过绑定账号找到该作品”。
原因是缓存和作品详情均为空时仍用链接 ID 合成了元数据；媒体、无音频和 ASR 异常也被同一个提示覆盖。
一次独立公开元数据检查成功，但后续媒体预检未完成，因此不能把元数据成功当作视频或文稿已取得。

## 本次修改

- 绑定信息为空不再合成已找到的作品；公开恢复最多一次，必须匹配原作品与平台。绑定媒体仅在 404/410 时恢复，登录、验证或限流不连续重试。
- 保留原始公开短链读取上下文；已有完整资料复用时也可补充短链，不重复转写。
- 真实元数据成功后先保存当前用户的资料；正常完成更新同一条资料，保留收藏/喜欢分类和已有非空元数据。无音频保存为正常内容状态。
- 单条失败页面保留预览；已有资料 ID 时显示“下载视频”。成功后的详情页也显示下载按钮。
- 新增普通 Web JWT 接口 `GET /api/notes/{note_id}/video/download`，只下载当前用户的资料。准备完成后再次检查账号、归属与平台连接状态。
- 下载视频完整校验后返回 MP4，最大 512 MB。每用户同时 1 个、全局同时 4 个、每用户每分钟 6 次；临时文件和并发槽在结束、断连及 Range 错误时清理。
- 浏览器显示准备状态和真实接收进度，支持取消与中文失败提示；JWT 只在同源请求头中传输。

真实平台若要求登录或验证，必须通过正常账号连接处理；本次不规避平台限制，也不承诺任意视频都能下载。
