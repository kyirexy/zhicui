## Why

客户端安装包目前由静态地址直接下载，服务端无法获知下载启动次数，管理员也无法判断 Android 与 Windows 客户端的实际分发情况。需要一套不采集个人信息、可按平台和日期查看的下载统计。

## What Changes

- 为 Android APK 与 Windows 安装包提供统一的可计数下载入口，计数后重定向到现有可信静态文件。
- 按自然日和平台聚合下载启动次数，不保存 IP、User-Agent、Cookie 或用户身份。
- 扩展管理端统计 API，返回累计、今日、近 7 日、平台拆分与近期日趋势。
- 在管理端概览展示下载量指标和趋势，不影响现有安装包与更新清单。
- 将应用内、官网和二维码的公开下载链接统一切换到计数入口。

## Capabilities

### New Capabilities

- `client-download-analytics`: 定义客户端可计数下载入口、隐私边界、聚合统计和管理端展示。

### Modified Capabilities

无。

## Impact

- 后端新增下载日聚合模型、公开下载重定向接口和管理端统计字段。
- 前端下载 URL 生成、二维码及管理端概览类型和界面。
- 启动时数据库建表机制；不新增第三方依赖，不改变安装包文件路径。
