## Why

用户目前必须进入视频库手动同步，并等待新视频完成文案提取后才能提问；使用频率高时，这段等待会反复打断使用。需要让用户在设置中选择自动同步周期，让知萃在运行期间提前拉取并准备新内容。

## What Changes

- 设置页新增“自动同步”区域，可关闭或选择每 30 分钟、1 小时、3 小时、6 小时、每天同步。
- 自动同步默认关闭，启用后在知萃运行期间按用户所选周期拉取最近 50 条抖音收藏。
- 同步完成后自动找出尚无完整文案的新视频，并复用现有批量文案提取任务。
- 记录当前设备的上次执行、结果和下次计划时间，设置页支持“立即同步”。
- 对同一用户增加跨组件/标签页运行锁，避免定时任务与手动操作重复启动。
- 抖音未连接、离线或同步失败时保留失败状态，并在下一个周期安全重试。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `douyin-library-sync-control`: 增加用户可配置的运行时自动同步、自动文案准备、执行状态和去重要求。

## Impact

- `frontend/src/lib/types.ts` 与 `SettingsContext`：新增设备级同步周期偏好。
- `frontend/src/lib/libraryAutoSync.ts`：调度、运行锁、状态记录和同步/提取编排。
- 全局 Provider：在已登录且应用运行时启动轻量调度器。
- 设置页：新增周期选择、即时执行和状态反馈。
- 后端 API 与数据库不变，复用现有采集、任务查询、资料列表和批量提取接口。
