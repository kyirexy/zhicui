## ADDED Requirements

### Requirement: 桌面端可靠展示视频封面
系统 SHALL 在桌面工作台、视频库和视频详情中优先使用知萃同源封面代理，并 SHALL 在加载失败时显示可恢复的占位状态。

#### Scenario: 代理封面可用
- **WHEN** 桌面端视频条目包含有效的 `cover_proxy_url`
- **THEN** 系统显示代理封面而不直接请求原始抖音图片地址

#### Scenario: 封面读取失败
- **WHEN** 封面代理返回错误或图片解码失败
- **THEN** 系统显示与卡片尺寸一致的占位状态
- **AND** 用户可以触发一次封面重试

### Requirement: 用户控制桌面本地媒体保存
系统 SHALL 允许桌面端用户开启或关闭“播放时自动保存”，并 SHALL 默认关闭自动保存。

#### Scenario: 自动保存关闭
- **WHEN** 用户未开启自动保存并播放一个未缓存视频
- **THEN** 系统仅使用远程按需视频流
- **AND** 不在本机创建视频文件

#### Scenario: 自动保存开启
- **WHEN** 用户开启自动保存并首次播放一个未缓存视频
- **THEN** 系统立即开始远程播放
- **AND** 在后台将该视频保存到当前本地目录
- **AND** 后续打开时优先播放本地副本

#### Scenario: 用户主动保存单条视频
- **WHEN** 用户在视频详情点击“保存到本地”
- **THEN** 系统保存该视频及可用封面
- **AND** 展示下载中、已保存或失败状态

### Requirement: 用户选择本地媒体目录
系统 SHALL 在桌面设置中展示当前媒体保存目录，并 SHALL 允许用户通过 Windows 原生目录选择器修改目录。

#### Scenario: 首次使用
- **WHEN** 用户第一次打开桌面本地媒体设置
- **THEN** 系统使用系统“视频/知萃”作为默认目录

#### Scenario: 选择新目录
- **WHEN** 用户选择一个可写目录
- **THEN** 系统将该目录用于后续保存
- **AND** 不自动移动此前已经保存的文件

#### Scenario: 取消目录选择
- **WHEN** 用户关闭原生目录选择器且未选择目录
- **THEN** 系统保留原目录和原设置

### Requirement: 本地媒体安全播放
系统 MUST 通过受限桌面协议向页面提供本地媒体，并 MUST 阻止网页读取未被媒体索引登记的本地文件。

#### Scenario: 播放已缓存视频
- **WHEN** 当前视频存在有效本地副本
- **THEN** 播放器使用 `zhicui-media://` 地址
- **AND** 支持标准 Range 请求和进度拖动

#### Scenario: 请求未登记文件
- **WHEN** 页面构造一个未出现在媒体索引中的本地媒体地址
- **THEN** 桌面协议返回未找到
- **AND** 不返回任何本地路径内容

#### Scenario: 页面提交不可信媒体 URL
- **WHEN** IPC 请求包含非知萃来源或非指定媒体路由
- **THEN** 主进程拒绝下载
- **AND** 不创建临时文件

### Requirement: 用户管理本地副本
系统 SHALL 在视频详情中展示当前本地缓存状态，并 SHALL 允许用户打开文件所在目录或删除本地副本。

#### Scenario: 打开所在目录
- **WHEN** 用户对已缓存视频点击“打开文件夹”
- **THEN** Windows 文件管理器打开并选中对应视频文件

#### Scenario: 删除本地副本
- **WHEN** 用户确认删除本地副本
- **THEN** 系统删除视频和关联封面文件
- **AND** 云端文稿、知识卡、计划和资料库记录保持不变
- **AND** 播放器回退到远程按需播放

### Requirement: 服务器不保存桌面视频
系统 SHALL 保持服务器和数据库不保存桌面端视频文件，并 SHALL 在桌面本地媒体设置中明确这一数据边界。

#### Scenario: 桌面端完成本地保存
- **WHEN** 一个视频已保存到用户电脑
- **THEN** 视频二进制仅存在于用户选择的本机目录
- **AND** 服务器数据库中不新增视频文件或本地路径字段

### Requirement: 非桌面端保持现有体验
系统 SHALL 只在检测到支持本地媒体桥接的桌面客户端时展示目录和本地缓存操作。

#### Scenario: Web 或 Android 打开设置
- **WHEN** 当前运行环境不是支持本地媒体桥接的 Windows 客户端
- **THEN** 系统不展示本地目录选择或本地文件操作
- **AND** 继续使用远程按需播放
