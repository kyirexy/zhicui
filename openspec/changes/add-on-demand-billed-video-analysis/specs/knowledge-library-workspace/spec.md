## ADDED Requirements

### Requirement: 视频详情以内联次级入口提供详细解析
视频详情 SHALL 保留普通摘要作为主操作，并在现有摘要区域提供详细解析次级入口。系统 MUST NOT 为详细解析增加内容 Tab、关键帧画廊或未请求状态徽标。

#### Scenario: 用户尚未请求详细解析
- **WHEN** 用户打开一个可解析视频详情
- **THEN** 摘要区域显示“使用详细解析”或“补充详细解析”的次级入口
- **AND** 列表不显示“待解析”状态

#### Scenario: 详细解析已完成
- **WHEN** 当前视频已有可用结果
- **THEN** 摘要区域显示已结合的关键场景数量和更新时间
- **AND** 结果用于刷新现有摘要

### Requirement: 批量解析位于现有更多操作中
资料库 SHALL 在现有批量栏“更多操作”的首项提供详细解析，并 SHALL 对所选资料计算缓存命中、实际处理和不支持数量。公众号和小红书图文 MUST NOT 被作为可执行项。

#### Scenario: 用户准备批量解析
- **WHEN** 用户选择多个跨平台视频并点击详细解析
- **THEN** 确认界面显示数量、推荐方案、预计时间、预计萃点和最高预留
- **AND** 提示任务可离页后台运行

### Requirement: 收费或 BYOK 使用底部确认 Sheet
免费单条 SHALL 可直接开始；付费、BYOK 或多条请求 SHALL 使用现有底部 Sheet 展示服务端报价、授权上限和结算说明。余额不足时 SHALL 提供免费方案或自有模型选择，首版 MUST NOT 显示无效充值按钮。

#### Scenario: 用户确认付费解析
- **WHEN** 用户在有效报价 Sheet 点击确认并开始
- **THEN** Sheet 立即关闭且任务进入后台
- **AND** 页面原位显示阶段而不阻塞浏览

### Requirement: 活动任务可跨页面恢复且不新增永久导航
详情、资料库和 Agent SHALL 通过 active-run API 恢复任务状态。AppHeader SHALL 仅在存在后台任务时显示临时解析状态入口，并使用现有全局 Sheet 展示任务。

#### Scenario: 用户离开后返回
- **WHEN** 用户在解析期间离开并重新打开应用
- **THEN** 系统从持久 API 恢复当前阶段、进度和结算结果
- **AND** 仅对 running、ready 或 failed 项显示状态

### Requirement: 移动端确认与状态可访问
底部 Sheet SHALL 避开安全区、恢复焦点、提供至少 44px 点击区域并向读屏器播报报价、运行状态和结果。

#### Scenario: 窄屏设备确认
- **WHEN** 用户在移动端打开收费解析 Sheet
- **THEN** 所有费用说明和确认按钮可完整滚动与触达
- **AND** 关闭后焦点返回触发入口
