## ADDED Requirements

### Requirement: 用户可以保存三平台博主来源
系统 SHALL 在现有同步视频 Sheet 内支持解析并保存抖音、B站和小红书官方博主主页，且 MUST 将来源限定到当前登录用户。

#### Scenario: 保存有效博主主页
- **WHEN** 用户提交受支持平台的有效博主主页并确认保存
- **THEN** 系统返回标准化博主 ID、名称、头像、主页和平台
- **AND** 同一用户重复保存同一博主时复用已有来源

#### Scenario: 拒绝非官方或不安全地址
- **WHEN** 用户提交非允许域名、携带凭据的 URL、本地地址或无法识别的标识
- **THEN** 系统返回可操作的校验错误
- **AND** 系统不向该地址发起网络请求

### Requirement: 博主同步只能由用户按需启动
系统 SHALL 只在用户显式选择一个已保存博主和最近 20、50 或 100 条后创建同步任务，MUST NOT 从同步、摘要、Agent 或自动化路径隐式启动。

#### Scenario: 用户启动一次同步
- **WHEN** 用户点击同步指定博主最近 N 条
- **THEN** 系统创建持久后台任务并立即允许用户离开 Sheet
- **AND** N 只允许为 20、50 或 100

#### Scenario: 重复点击同一博主
- **WHEN** 同一用户对已有活动任务的博主再次提交同步
- **THEN** 系统返回现有任务
- **AND** 不创建第二个任务或重复处理作品

### Requirement: 同步按作品增量且尊重永久移除
系统 SHALL 按当前用户、平台和作品 ID 去重，只为新作品准备普通文稿，并 SHALL 永久跳过用户已永久移除的作品。

#### Scenario: 再次同步没有新作品
- **WHEN** 最近 N 条作品均已存在
- **THEN** 任务成功并报告新增为零及对应复用数量
- **AND** 不再次执行字幕提取或 ASR

#### Scenario: 作品曾被永久移除
- **WHEN** 抓取结果包含当前用户已永久移除的作品
- **THEN** 系统将该项记录为 `skipped_removed`
- **AND** 不重新创建 Note 或媒体处理任务

### Requirement: 同步任务持久、可恢复且部分失败隔离
系统 SHALL 持久记录同步阶段、心跳、计数和脱敏结果，并 SHALL 在服务器重启后安全恢复未完成任务。

#### Scenario: 单条作品处理失败
- **WHEN** 一个作品的解析、字幕或 ASR 失败但其他作品成功
- **THEN** 任务完成为 `partial`
- **AND** 成功作品继续出现在资料库，失败项只返回脱敏错误

#### Scenario: 服务器在任务中途重启
- **WHEN** 活动任务心跳租约过期
- **THEN** 恢复器重新排队任务
- **AND** 已完成作品通过幂等记录复用而不重复转写

### Requirement: 三平台凭证与连接器按既定策略隔离
系统 SHALL 让 B站公开主页无需登录、抖音使用当前用户作用域会话、小红书使用管理员配置的加密服务凭证，并 MUST 按平台健康状态门控同步。

#### Scenario: 抖音用户会话过期
- **WHEN** 用户同步抖音博主但其作用域 Cookie 无效
- **THEN** 任务返回需要重新授权的状态
- **AND** 不改用其他用户或平台共享 Cookie

#### Scenario: 小红书服务凭证不可用
- **WHEN** 小红书 sidecar 或管理员凭证健康检查失败
- **THEN** 小红书指定博主入口不可启动并显示明确原因
- **AND** B站和抖音入口保持可用

### Requirement: 同步只保存资料与普通文稿
系统 MUST NOT 因博主同步执行 AI 摘要、视觉模型、详细视频解析或媒体归档，且 SHALL 在字幕或 ASR 结束后清理临时媒体。

#### Scenario: 新视频同步成功
- **WHEN** 系统成功导入博主的新视频
- **THEN** 数据库只保存标准化元数据、普通文稿、来源映射和任务诊断
- **AND** 不保存视频、音频、Cookie、签名媒体 URL、base64 或本地路径

#### Scenario: 小红书主页包含图文
- **WHEN** 小红书博主最近 N 条中包含非视频笔记
- **THEN** 系统跳过图文并在检查数量中保留该结果
- **AND** 不为图文创建资料或详细解析入口

### Requirement: 用户可以管理保存的博主和后台状态
系统 SHALL 允许用户查看保存博主、最近同步摘要、活动任务和近期任务，并 SHALL 允许取消任务或停用博主。

#### Scenario: 停用没有活动任务的博主
- **WHEN** 用户删除一个已保存博主
- **THEN** 系统停用该来源且不再显示为可同步选择
- **AND** 该博主已经导入的资料继续保留

#### Scenario: 博主仍有活动任务
- **WHEN** 用户尝试删除仍有 queued 或运行中任务的博主
- **THEN** 系统拒绝删除并要求先取消任务

### Requirement: 管理员控制功能发布和连接器健康
系统 SHALL 在现有管理配置中提供默认关闭的总开关、连接器健康测试、小红书加密凭证和并发配置，不新增主导航。

#### Scenario: 管理员尚未启用功能
- **WHEN** 总开关关闭
- **THEN** 用户同步 Sheet 不显示可操作的指定博主入口
- **AND** 创建来源或任务 API 返回功能未启用

#### Scenario: 管理员测试小红书连接器
- **WHEN** 管理员提交服务凭证并执行连接测试
- **THEN** 服务端加密保存凭证并只返回掩码、健康状态和测试时间
- **AND** 凭证原文不进入 API 响应、日志或审计详情
