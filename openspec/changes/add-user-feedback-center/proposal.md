## Why

当前用户在网页端或手机端遇到问题、提出建议时，没有产品内反馈入口，也没有可追踪的处理状态；管理员只能依靠外部沟通收集问题，难以关联用户、页面和设备环境。需要建立一个轻量但完整的反馈闭环，让用户随时提交，管理员集中查看和处理。

## What Changes

- 在已登录用户界面的右下角增加反馈入口，桌面端和移动端均避开导航栏与安全区。
- 提供反馈分类、主题、详细描述和自动采集的页面/设备环境信息；不采集令牌、密码等敏感数据。
- 用户可查看最近提交的反馈及处理状态，避免重复提交和“提交后无下文”。
- 新增用户反馈 API 与独立数据库表，所有记录按用户隔离。
- 管理端新增反馈中心，支持状态、分类、关键词筛选，查看用户、内容、页面和设备信息，并更新处理状态与回复。
- 管理员处理动作写入审计日志，用户提交写入用户活动日志。
- 将同一功能同步到 Capacitor Android 安装包并部署正式环境。

## Capabilities

### New Capabilities

- `user-feedback-center`: 覆盖用户反馈提交、个人反馈历史、管理端集中处理、权限隔离、审计以及跨端浮动入口。

### Modified Capabilities

无。

## Impact

- 后端：新增 Feedback ORM 模型、服务层和用户/管理员 API；启动时通过现有 `create_all` 创建新表。
- 前端：新增全局反馈入口与对话框、API 类型和管理端反馈视图；调整固定元素安全区样式。
- 数据库：新增 `feedback` 表，不保存图片、视频、令牌或密码。
- 运维：重新构建网页端与 Android APK，沿用现有 Gitee/Jenkins 发布链路。
