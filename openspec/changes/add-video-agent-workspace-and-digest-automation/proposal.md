## Why

知萃现有的视频问答只存在于视频库侧栏，缺少主流 AI Agent 产品具备的独立任务空间、持久对话和可复用资料范围；用户也无法让“昨天新整理的视频”自动变成每天可继续追问的摘要。现在需要把视频资料从一次性问答升级为知萃的核心 Agent 上下文，并让结果可按计划送达。

## What Changes

- 新增独立的视频 Agent 工作台，提供任务历史、持久对话、固定输入区和可核对的资料依据。
- 用户可在对话中选择“全部已有文案”“昨天新整理”“抖音收藏”“喜欢”“我的作品”或手动选择视频，并随时查看本次实际参考的视频数量与明细。
- 每个对话冻结一份用户自有的视频资料快照，避免资料范围在回答过程中悄然变化；回答继续复用现有的完整文案检索、深度分析和联网校验能力。
- 新增每日视频摘要自动化：用户可设置执行时间、时区、收件邮箱和可编辑指令，系统对昨天新整理进知萃的视频生成摘要。
- 每次自动化运行都会保存结果、资料范围、发送状态和错误，可从结果继续追问并迭代下一次指令。
- 邮件服务未配置时仍生成可预览的摘要并明确标记“未发送”，不伪造成功；定时执行使用持久化抢占租约，避免多实例重复运行。
- 桌面端、网页端和移动端均增加 Agent 入口；移动端用抽屉/底部面板承载任务历史和资料选择，保持聊天输入始终可用。

## Capabilities

### New Capabilities

- `video-grounded-agent-workspace`: 覆盖视频资料范围选择、持久 Agent 任务/消息、依据展示以及跨端 Agent 工作台。
- `scheduled-video-digests`: 覆盖每日摘要计划、昨天新增资料范围、运行记录、邮件投递与可继续追问的结果。

## Impact

- 后端新增 Agent 会话、消息、自动化及运行记录模型与用户级 API。
- 新增轻量后台调度服务和基于标准库的 SMTP 投递；不引入第三方调度依赖。
- 扩展视频来源元数据，支持按收藏/喜欢/作品和同步时间过滤，同时继续只持久化文案与元数据，不保存视频文件。
- 前端新增 `/agent` 工作台、导航入口、资料选择器、自动化编辑与运行记录 UI，并复用现有视频问答能力。
- 新增可选 SMTP 环境配置；未配置环境保持安全降级。
