## Why

当前“视频资料”页只提供单列资料行，桌面端在资料数量较多时扫描效率偏低；单卡管理菜单还会在窄内容区被压缩成竖排，并触发多余滚动条。用户已明确需要在列表与网格之间切换，同时继续使用现有的抖音多选和批量处理能力。

## What Changes

- 在视频资料工具栏增加“列表 / 网格”布局切换，并在本地记住用户选择。
- 列表与网格共用搜索、筛选、预览、抖音复选、全选和底部批量操作状态。
- B站和小红书支持两种展示布局，但不获得仅抖音支持的批量管理能力。
- 移除单条抖音卡片上的冗余三点管理菜单；将“删除文案与摘要”收口到选择一条资料后的底部批量菜单，保留原有确认流程。
- 修复平台标签横向滚动区意外显示纵向滚动条的问题。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `multi-platform-video-library-import`: 视频资料统一展示要求增加列表/网格切换、布局选择持久化，以及按平台能力显示选择操作的约束。

## Impact

- 影响 `frontend/src/app/library/page.tsx`、视频资料卡片、跨平台资料行和对应 CSS Module。
- 不修改 API、数据库、同步链路、用户数据隔离或第三方依赖。
- 替代尚未归档的 `redesign-video-library-reference-workspace` 中“暂不提供视图切换”的旧产品决定。
