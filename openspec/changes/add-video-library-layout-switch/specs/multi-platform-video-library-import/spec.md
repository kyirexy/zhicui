## MODIFIED Requirements

### Requirement: 视频资料页统一展示跨平台来源

视频资料页 SHALL 在不改变主导航顺序的前提下展示抖音、B 站和小红书资料，SHALL 提供平台筛选、平台徽标、搜索和打开完整文案的操作，并 SHALL 允许用户在列表与网格布局间切换；布局变化 MUST 保留当前搜索、筛选、预览和已选抖音资料，且系统 SHALL 在本地记住有效的布局选择。系统 MUST 根据平台现有能力呈现选择与管理操作，不得向 B站或小红书资料暴露仅抖音支持的批量动作。

#### Scenario: 用户选择全部来源

- **WHEN** 用户在视频资料页选择“全部”
- **THEN** 可见资料包含当前用户的抖音、B 站和小红书资料
- **AND** 每条资料显示明确的平台归属和文案状态

#### Scenario: 用户筛选小红书

- **WHEN** 用户选择“小红书”平台筛选
- **THEN** 页面只显示当前用户的小红书导入资料
- **AND** 已输入搜索关键词继续生效

#### Scenario: 用户切换资料布局

- **WHEN** 用户从列表切换到网格，或从网格切换到列表
- **THEN** 当前资料、搜索、平台筛选和已选抖音资料保持不变
- **AND** 用户刷新页面后继续使用最近一次有效的布局选择

#### Scenario: 用户在网格中多选抖音资料

- **WHEN** 用户在网格布局勾选一个或多个抖音视频
- **THEN** 所选视频使用与列表布局相同的选择状态和底部批量操作
- **AND** 切换布局不会清空已选视频

#### Scenario: 用户在网格中查看跨平台资料

- **WHEN** 用户在网格布局查看 B站或小红书资料
- **THEN** 卡片保留详情、摘要和来源等已有动作
- **AND** 卡片不显示抖音专属复选、移出或永久隐藏动作

#### Scenario: 移动端导入

- **WHEN** 用户在窄屏设备打开视频资料页
- **THEN** 导入输入、提交按钮、来源筛选和结果反馈保持可触控且不被底部导航遮挡
- **AND** 当前布局不会造成横向溢出
