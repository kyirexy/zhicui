## Why

首页仍把知萃描述成多平台单链接提取工具，分散了用户对当前核心能力“抖音批量视频库”的注意力，也让首次访问者难以快速理解同步、文案提取、批量问答和行动转化的完整价值。

## What Changes

- 首页主叙事收紧为抖音视频库，不再展示公众号、B站、YouTube、小红书等平台字样。
- 首屏优先介绍从抖音收藏、喜欢和个人作品建立批量视频库的核心流程。
- 使用产品界面式预览展示“同步视频、自动生成完整文案、整库 AI 问答、创建计划与知识卡”的结果。
- 保留单条链接提取入口，但将其降为次要入口，避免与批量视频库争夺首屏焦点。
- 为桌面端和移动端提供清晰、紧凑且可操作的入口，主要按钮直接进入视频库。

## Capabilities

### New Capabilities

- `douyin-library-homepage`: 规定首页围绕抖音批量视频库的内容层级、核心流程展示、入口和响应式体验。

### Modified Capabilities

无。

## Impact

- 主要影响 `frontend/src/app/page.tsx` 及其首页专用样式或展示组件。
- 不修改现有提取、视频库、认证或后端 API 行为。
- 不增加第三方依赖；继续使用现有 Next.js、Tailwind CSS v4、图标与设计变量。
