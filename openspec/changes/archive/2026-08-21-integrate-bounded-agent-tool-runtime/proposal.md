## Why

Agent V2 已具备持久 Turn、分层研究和证据校验，但视频研究步骤仍由固定函数直接串接，重复调用保护也仅停留在独立实现与单元测试中。需要把这些领域步骤统一纳入有界工具运行时，才能真正兑现可取消、可恢复、可观测和防循环的 Agent 行为。

## What Changes

- 新增仅面向视频研究领域的 `AgentTool` 协议、白名单注册表与统一执行器，不开放 Shell、文件编辑或任意网络工具。
- 每次工具调用统一执行参数规范化、重复调用检测、Turn 取消检查、租约检查、结果大小限制和阶段事件记录。
- 将来源扫描、文稿映射、证据聚类/验证等既有研究步骤通过注册工具执行，同时保持现有回答合同和 V1 回退兼容。
- 同参连续第三次调用时记录提醒并返回给研究编排器；第五次时终止该路径并写入可恢复事件。
- 补充单元、集成和真实界面回归，验证刷新恢复、取消、重试和移动端展示。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `durable-video-research-agent`: 将“受限的视频领域工具循环”细化为统一注册表/执行器、调用事件、重复熔断、取消与租约边界。

## Impact

- 后端：`backend/app/services/agent_*`、`ai_juicer.py`、Agent Turn 事件与测试。
- 前端：不改变公开 API；继续消费既有 `turn.progress` 事件，必要时显示更精确的工具阶段消息。
- 数据：复用现有 `AgentEvent`，不新增迁移；事件载荷只保存脱敏摘要和计数，不保存完整文稿或密钥。
- 兼容性：保留现有 `/api/agent/*` 请求/响应、旧会话和单次计费语义。
