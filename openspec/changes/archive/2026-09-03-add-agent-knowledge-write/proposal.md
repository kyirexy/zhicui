## Why

当前 Agent 能回答问题和创建行动计划，但无法在用户明确要求时把有价值的结论直接沉淀为个人知识，用户仍需手工复制整理。新增受控的知识写入能力，可以让对话自然衔接到知识库，同时避免普通聊天被误保存。

## What Changes

- Agent 识别用户明确的“保存、记录、整理并写入知识库”等意图。
- Agent 将用户指定的内容或当前对话中的目标内容整理为标题、摘要和正文，并写入当前用户的知识库。
- 写入完成后返回可识别的知识创建结果及知识条目入口。
- 普通问答、含糊表达和仅讨论知识库时不自动写入。
- 写入失败时回滚本次创建，不留下空白或半成品知识条目。

## Capabilities

### New Capabilities

- `agent-knowledge-creation`: Agent 根据用户明确意图整理并创建用户隔离的知识条目，并返回可打开的结果。

### Modified Capabilities

无。

## Impact

- 后端 Agent 意图识别、工具执行与消息结果结构。
- 现有 `knowledge_entries` 数据模型和知识库查询接口（复用，不新增数据库表）。
- Agent 前端消息结果展示与跳转。
- Agent 知识创建相关自动化测试。
