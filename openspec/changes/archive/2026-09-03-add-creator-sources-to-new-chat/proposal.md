## Why

AI 问答的新会话只能逐条选择视频；用户已经按博主同步了一组资料，却不能直接把该博主的已就绪视频加入会话。当前入口还会跳转到视频 Tab，打断提问流程。

## What Changes

- 在新会话的资料选择面板中增加“博主”入口，与“全部、抖音、B站”并列。
- 直接展示当前用户已保存的博主，以及每位博主可用于问答的视频数量。
- 点击博主后，在当前面板内一次选择该博主已同步且已有完整文稿的视频；再次点击可取消整组选择。
- 对超出单会话上限、没有可用视频、读取失败等状态给出就地反馈，不跳转到视频 Tab。
- 扩展博主列表响应，返回经过用户权限过滤的可用 `note_id` 集合，供新会话安全建立资料选择。

## Capabilities

### New Capabilities

- `creator-source-chat-selection`: 在 AI 问答新会话中按博主整组选择已同步视频资料。

### Modified Capabilities

- `saved-creator-source-sync`: 博主列表需要暴露当前用户可用于问答的已就绪资料标识。

## Impact

- 前端：AI 问答资料选择器、博主列表 API 类型和移动端响应式样式。
- 后端：博主来源序列化响应增加只属于当前用户的已就绪资料标识。
- 不改变同步采集、文稿生成和 Agent 会话快照规则，不增加第三方依赖。
