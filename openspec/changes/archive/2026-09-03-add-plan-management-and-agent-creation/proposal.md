## Why

行动计划虽已有删除接口，但列表只显示无文字的垃圾桶图标，默认“今日”视图也没有管理入口，用户难以发现。知萃 Agent 同样已经具备结构化计划生成和 `plan.create` 产品动作，却没有把用户自然语言中的明确创建意图接入持久化计划能力。

## What Changes

- 在行动计划首页提供始终可见的“管理计划”入口，并在目标列表中使用明确的“删除”文字操作与二次确认。
- 为知萃 Agent 增加高置信度的计划创建意图识别，只在用户明确要求创建、制定或生成行动计划时触发。
- 复用现有计划生成、规范化和持久化服务，将 Agent 创建结果保存到当前用户账户，并在回答中返回可打开的计划信息。
- 为计划创建失败、模型不可用和非创建型计划咨询保留安全退路；普通问答不得误创建计划。

## Capabilities

### New Capabilities
- `agent-plan-creation`: 知萃 Agent 从明确的自然语言请求生成并持久化当前用户的行动计划。

### Modified Capabilities
- `clear-action-plan-workspace`: 计划管理与删除入口必须在默认视图和窄屏设备上可发现，并使用明确文字而不是仅依赖图标含义。

## Impact

- 前端：行动计划工作台页面及响应式样式。
- 后端：Agent 计划意图判断、计划生成/持久化编排及 Agent 回答结果。
- 测试：计划意图边界、用户隔离、创建结果和删除入口回归。
- 不新增第三方依赖，不改变现有计划删除 API。
