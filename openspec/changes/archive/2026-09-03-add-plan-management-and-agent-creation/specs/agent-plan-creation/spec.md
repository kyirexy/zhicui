## ADDED Requirements

### Requirement: Agent 从明确自然语言创建行动计划

知萃 Agent SHALL 在当前用户明确要求创建、制定、生成或安排一项行动计划时，将自然语言要求转换为结构化计划并保存到当前用户账户。

#### Scenario: 用户明确要求创建计划
- **WHEN** 用户在知萃 Agent 中输入“帮我制定一个 21 天英语学习计划”等明确创建请求
- **THEN** 系统使用该请求和当前可用资料生成标题、周期与可执行任务
- **AND** 将计划保存到当前用户账户
- **AND** Agent 回答包含创建成功说明和可打开的计划标识

#### Scenario: 用户基于当前资料创建计划
- **WHEN** 创建请求发生在包含已选视频资料的会话中
- **THEN** 系统将用户要求与有界的资料文稿共同用于计划生成
- **AND** 创建的计划保持当前用户隔离

### Requirement: 计划创建写操作必须高置信度触发

Agent MUST NOT 因一般计划咨询、评价、解释、否定表达或不完整意图自动创建持久化计划。

#### Scenario: 用户只询问如何制定计划
- **WHEN** 用户询问“这个计划合理吗”或“怎么制定学习计划”但没有要求系统创建
- **THEN** 系统继续普通问答
- **AND** 不新增行动计划

#### Scenario: 用户明确否定创建
- **WHEN** 用户说“不要创建计划，只给我建议”
- **THEN** 系统不调用计划创建能力
- **AND** 不写入计划数据

### Requirement: 创建失败不得留下不完整计划

当计划生成或保存失败时，系统 SHALL 返回可理解的失败结果，并 MUST NOT 保存空标题、空任务的占位计划或孤立的半完成 Agent 消息。

#### Scenario: 模型生成不可用
- **WHEN** 计划生成模型失败或返回无效结构
- **THEN** 本次 Agent Turn 进入可重试失败状态
- **AND** 当前用户的计划列表保持不变
