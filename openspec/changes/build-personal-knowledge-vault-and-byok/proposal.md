## Why

“我的知识”仍然围绕 AI 卡片类型组织，无法承载用户自己写下的理解、想法和长期沉淀；同时视频 Agent 在模型只返回推理内容时会丢失真实错误并直接变成 502。用户还需要在平台低成本默认能力与自带模型供应商之间自由选择。

## What Changes

- **BREAKING** 删除知识库中的食谱、洞察、历史、产品、计划、通用类型 Tab，以及以卡片样式为核心的浏览方式。
- 将“我的知识”升级为永久个人知识库，以统一内容流承载视频生成的知识和用户原创笔记。
- 提供原创知识的新建、编辑和删除能力，并允许标题、正文和来源说明参与搜索。
- 为视频 Agent 增加空正文恢复策略和原始异常记录，避免可恢复的模型响应直接变成无信息 502。
- 新增每用户独立的 AI 供应商配置页，支持平台默认服务和 OpenAI 兼容自定义服务；密钥加密保存且读取时只返回掩码。
- 展示平台默认服务的基础额度/能力边界，以及自带供应商可解锁的能力，但本次不接入支付结算。

## Capabilities

### New Capabilities
- `personal-knowledge-entry`: 用户原创知识条目的持久化、检索、编辑与删除。
- `user-ai-provider`: 每用户 AI 供应商配置、加密密钥、连接测试与运行时解析。
- `agent-response-recovery`: Agent 对空正文模型响应的受控恢复和可诊断错误记录。

### Modified Capabilities
- `knowledge-library-workspace`: 从卡片类型筛选库改为混合视频知识与原创理解的永久个人知识库。
- `grounded-web-research`: Agent 调用应使用当前用户解析后的供应商配置并在可恢复的空正文响应后重试。

## Impact

- 后端新增用户知识条目和用户 AI 配置模型、SQLite 启动迁移、用户级 API 与运行时配置解析。
- Agent 路由和 LLM 调用链增加用户上下文、恢复重试与错误日志。
- 前端重做 `/notes` 列表与详情体验，并在 `/settings` 增加 AI 服务配置。
- 继续兼容已有视频笔记数据；不删除历史 `card_type` 字段，只停止在个人知识库中将其作为导航结构。
