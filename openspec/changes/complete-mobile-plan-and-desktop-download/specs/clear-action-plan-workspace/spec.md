## MODIFIED Requirements

### Requirement: 移动端保留完整计划能力

移动网页和 Capacitor Android SHALL 通过独立“计划”Tab 提供与桌面端相同的“全部计划 / 今日安排 / 本周复盘”切换、计划创建、查看、删除、任务编辑和打卡能力，并 SHALL 为单手触控、软键盘和设备安全区提供专用布局。

#### Scenario: 用户在窄屏设备操作计划

- **WHEN** 视口宽度小于移动端断点
- **THEN** 标题、计划摘要和一级视图切换在紧凑首屏内依次出现
- **AND** 计划内容按单列展示且信息顺序为目标、进度、下一步
- **AND** 主要按钮与图标按钮具有至少 44px 的可触控区域
- **AND** 悬浮新增、快速新增和删除确认不被底部导航、软键盘或安全区遮挡

#### Scenario: 用户使用移动端完整管理计划

- **WHEN** 用户从计划 Tab 创建计划并进入计划详情
- **THEN** 用户可以添加、编辑、排序和完成任务
- **AND** 用户可以返回计划列表或通过带确认的操作删除计划
- **AND** 弹层关闭后焦点返回原触发控件
