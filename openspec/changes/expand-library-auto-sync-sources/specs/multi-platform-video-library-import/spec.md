## ADDED Requirements

### Requirement: 设置页说明多渠道自动同步边界
系统 SHALL 在自动同步设置中区分可后台读取的抖音范围与需要用户在本机官方页面确认的 B 站、小红书账号范围，并 MUST NOT 由后台定时器静默启动第三方平台浏览器采集。

#### Scenario: 用户查看自动同步范围
- **WHEN** 用户打开同步设置
- **THEN** 页面说明抖音收藏、喜欢和作品会按周期自动更新
- **AND** 页面说明 B 站、小红书收藏和喜欢需要用户主动确认

#### Scenario: 用户管理其他平台
- **WHEN** 用户需要更新 B 站或小红书账号资料
- **THEN** 设置页提供进入视频资料页的直接入口
- **AND** 同步仍使用按用户和平台隔离的本机会话

#### Scenario: 后台同步到期
- **WHEN** 自动同步周期到期且用户没有打开平台确认页面
- **THEN** 系统不打开 B 站或小红书浏览器窗口
- **AND** 不声称这两个平台已经完成账号同步
