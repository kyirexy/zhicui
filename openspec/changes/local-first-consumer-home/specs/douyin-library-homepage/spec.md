## MODIFIED Requirements

### Requirement: 首页适配桌面与移动端
系统 SHALL 在桌面端与移动端保持核心定位、主要操作和批量处理结果清晰可读，并 SHALL 在已登录 Windows 桌面端优先呈现个人继续使用入口而不是管理统计看板。

#### Scenario: 移动端浏览
- **WHEN** 首页视口宽度小于桌面断点
- **THEN** 主要标题和入口保持在前部
- **AND** 批量视频库预览以单列或紧凑布局呈现
- **AND** 交互目标满足移动端触控尺寸

#### Scenario: 桌面浏览器浏览
- **WHEN** 首页处于桌面宽度且不是 Windows 桌面客户端
- **THEN** 页面以不对称布局同时展示产品说明和视频库工作台预览

#### Scenario: 已登录 Windows 桌面端浏览
- **WHEN** 用户在 Windows 桌面客户端打开首页
- **THEN** 页面在欢迎区后直接展示“继续整理”和“今天要做”
- **AND** 页面不展示“工作概览”“最近一次云端数据”或视频、文案、任务统计卡片
