## ADDED Requirements

### Requirement: 首页默认恢复当前用户的本地快照
系统 SHALL 默认在当前设备保存登录用户首页所需的近期视频、知识和计划快照，并 MUST 按用户标识隔离。

#### Scenario: 存在当前用户快照
- **WHEN** 用户打开桌面首页且当前设备存在该用户的有效快照
- **THEN** 系统先展示本地快照
- **AND** 系统在后台刷新账号数据

#### Scenario: 切换账号
- **WHEN** 另一个用户在同一设备登录
- **THEN** 系统不得展示前一个用户的本地快照

### Requirement: 本地快照保持最小化
系统 MUST 只保存首页展示所需的有限条目与统计上下文，并 MUST NOT 在工作区快照中保存完整文案正文、API Key、认证令牌或视频二进制。

#### Scenario: 保存首页快照
- **WHEN** 首页成功读取账号数据并启用了本地快照
- **THEN** 系统保存有限数量的近期条目和更新时间
- **AND** 快照不包含完整文案正文或视频文件

### Requirement: 用户控制本地快照
系统 SHALL 在设置中允许用户开启或关闭近期工作区本地保存，并 SHALL 提供清除本机快照的操作。

#### Scenario: 关闭本地快照
- **WHEN** 用户关闭“在当前设备保留最近内容”
- **THEN** 系统删除已有工作区快照
- **AND** 后续首页刷新不再写入快照

#### Scenario: 清除本地数据
- **WHEN** 用户点击清除本机近期内容
- **THEN** 系统删除所有用户的工作区快照
- **AND** 不删除账号服务端数据或本地视频文件

### Requirement: 本地存储失败时安全回退
系统 SHALL 在浏览器存储不可用、损坏或超出配额时继续通过现有 API 加载首页。

#### Scenario: 快照读取失败
- **WHEN** 本地快照无法解析或读取
- **THEN** 系统忽略该快照并正常请求账号数据
- **AND** 不阻止用户进入首页
