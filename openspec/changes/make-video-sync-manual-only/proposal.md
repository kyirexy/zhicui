## Why

平台账号同步会触发真实的第三方列表读取；在应用启动、进入页面或定时器到期时自动发起这些请求，会在用户无感知的情况下增加抖音/B站访问频率，并提高风控概率。同步应当只发生在用户明确点击操作之后，让用户控制请求时机和范围。

## What Changes

- **BREAKING**：移除设备端自动同步周期、启动自动同步和到期调度能力，已有自动同步偏好不再触发任何平台请求。
- 保留收藏、喜欢、作品、博主近期作品和全部清单等手动同步入口；每次任务都必须来自用户当次明确点击。
- 设置页与同步界面改为“仅手动同步”的清晰说明，不再展示可启用的自动同步周期。
- 后台轮询只用于跟踪已经由用户启动的任务，不得创建新的平台同步任务。
- 绑定账号或完成登录只更新连接状态，不自动读取收藏、喜欢、作品或博主目录。

### Modified Capabilities

- `douyin-library-sync-control`: 将可配置自动同步改为所有平台资料仅允许用户显式手动触发，并区分任务状态轮询与新任务创建。
- `multi-platform-video-library-import`: 明确绑定账号、打开页面和应用启动不得静默触发 B站或其他平台资料采集。

## Impact

- 前端全局调度器、自动同步设置卡、设置文案和本地自动同步状态。
- 抖音/B站同步弹层、博主同步页面及账号绑定后的触发逻辑。
- 同步相关前端测试；后端任务 API 继续保留并只接受显式请求，不改变已有任务恢复和重试机制。
