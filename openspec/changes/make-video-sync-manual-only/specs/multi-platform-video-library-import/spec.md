## ADDED Requirements

### Requirement: 多平台账号连接不自动采集资料

系统 MUST 将账号绑定和资料同步视为两个独立操作；抖音、B站及其他平台的账号连接成功只 SHALL 更新连接状态，不得自动读取收藏、喜欢、投稿、自己的作品或博主目录。

#### Scenario: 平台账号连接成功

- **WHEN** 用户完成平台账号绑定或登录确认
- **THEN** 系统显示账号已连接
- **AND** 系统等待用户选择来源并点击同步

#### Scenario: 应用恢复联网

- **WHEN** 已连接平台账号的客户端从离线恢复联网
- **THEN** 系统可以刷新轻量连接状态
- **AND** 系统不自动启动任何平台资料采集

#### Scenario: 用户查看手动同步说明

- **WHEN** 用户进入同步设置
- **THEN** 系统明确说明所有平台资料仅手动同步以及这样做用于降低账号风控
- **AND** 系统不提供可启用的自动同步周期控件
