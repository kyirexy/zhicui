## Why

计划模块已经具备任务编辑与“今日 / 目标 / 复盘”外形，但仍由系统自动挑选行动、只能从视频创建计划，且复盘缺少完成时间数据。用户无法把它当作日常计划产品持续使用，视觉上也存在两代全局样式叠加，需要升级为安静、可信、移动端优先的今日行动工作台。

## What Changes

- 支持脱离视频手动创建计划，并通过一个全局快速入口新增任务或计划。
- 让用户每天确认最多三项跨计划焦点任务，同时保留系统推荐、今日其他待办和默认收起的逾期任务。
- 为任务增加稳定顺序、焦点日期与完成时间，支持触控拖拽和键盘/按钮排序。
- 将复盘升级为基于真实完成时间、排期与当前状态计算的周回顾，并明确旧数据的历史不完整边界。
- 在计划详情增加 AI 调整预览与确认应用流程；预览不写库，应用时保护已完成任务并校验并发版本。
- 把计划界面收敛为一个局部样式系统，使用暖白、雾灰、深墨与低饱和薄荷色，保持浅色、深色、网页、Electron 与 Capacitor 一致。
- 保持现有视频转计划入口、JWT 用户隔离、API envelope、旧任务 JSON 和静态导出兼容。

## Capabilities

### New Capabilities

- `manual-plan-creation`: 用户可以手动创建空计划或带首个任务的计划，并从工作台快速记录任务。
- `plan-weekly-review`: 系统按自然周返回真实完成、顺延、逾期和各计划推进数据，并标注不完整历史。
- `plan-coaching-preview`: AI 可以基于当前计划与可选视频上下文生成无副作用的调整预览，并在用户确认后安全应用。

### Modified Capabilities

- `clear-action-plan-workspace`: 今日页改为用户确认三项焦点，目标页使用紧凑计划行，复盘页展示真实周数据。
- `plan-task-management`: 任务增加稳定顺序、焦点与完成时间，并支持原子排序和计划开始日期。
- `plan-execution-overview`: 执行概览增加指定日期、已选焦点、推荐候选与未排期任务。
- `plan-data-isolation`: 手动创建、焦点、排序、复盘和 AI 调整同样必须按当前用户隔离。

## Impact

- 后端计划 ORM、启动时加法迁移、计划 service、AI 计划生成与 FastAPI 路由。
- 前端共享计划类型/API、计划工作台页面与计划任务组件。
- 新增局部 CSS Module；不覆盖现有无关的全局样式修改。
- 新增 `@dnd-kit/core`、`@dnd-kit/sortable` 与 `@dnd-kit/utilities`，均兼容 React 19。
- SQLite 与 PostgreSQL 都需支持新增可空列；旧数据无需批量重写。
