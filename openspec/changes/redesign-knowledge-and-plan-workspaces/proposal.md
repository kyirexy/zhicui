## Why

当前知识库使用大面积深绿色与视觉预览卡片，难以支撑几十到上百条视频资料的快速检索；计划工作台虽然已有排期、打卡和编辑能力，但入口与信息层级仍像“计划卡片集合”，用户第一眼无法判断现在该做什么。需要把两处界面统一为更轻、更成熟的知识与执行工作台，同时保持桌面、移动网页和 Android 一致。

## What Changes

- 将知识库改为中性浅色的“内容对象库”：突出搜索、最近内容、类型筛选和高密度列表，并保留可切换的卡片视图。
- 知识库提供清晰的全库提问入口，复用现有视频 Agent，不把 AI 对话做成孤立入口。
- 将计划首页收敛为“今日 / 目标 / 复盘”三个主视图，默认直接回答“现在最应该做什么”。
- 在“今日”中聚合最多三个优先行动并支持直接打卡；在“目标”中呈现计划进度与下一步；在“复盘”中基于真实任务数据展示完成情况和需要调整的计划。
- 保留计划删除、任务增删改、排期、优先级、时长和 AI 视频计划调整等现有能力，重新组织信息层级而不伪造尚未接入的日历、精力或冲突检测。
- 为窄屏和 Capacitor Android 提供同等功能、44px 触控区、安全区适配和紧凑单列布局。

## Capabilities

### New Capabilities

- `knowledge-library-workspace`: 覆盖可搜索的知识对象库、列表/卡片视图、内容类型导航、最近内容和全库提问入口。

### Modified Capabilities

- `clear-action-plan-workspace`: 将计划工作台扩展为“今日 / 目标 / 复盘”执行闭环，并定义移动端相同能力和真实数据边界。

## Impact

- 前端：`frontend/src/app/notes/page.tsx`、`frontend/src/app/plans/page.tsx`、知识与计划组件、`frontend/src/app/globals.css`。
- 后端/API：本轮优先复用现有笔记检索、计划概览、任务 CRUD 与计划 Agent 接口；不新增媒体存储，也不改变服务器不保存视频文件的约束。
- 移动端：Next 静态导出与 Capacitor Android 共用同一响应式实现。
- 依赖：不引入新的 UI 或动画依赖，复用现有图标、计划接口和 Agent 工作区。
