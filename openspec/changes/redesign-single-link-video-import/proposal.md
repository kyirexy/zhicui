## Why

当前单条解析完成后仍在入口页渲染“知识卡”，与视频资料库中的单条视频详情形成重复体验，也让用户看不到原视频。单条解析应当是把视频导入资料库的过程，完成后直接进入统一的视频详情工作区。

## What Changes

- 将“单条解析”页面定位为单条视频导入入口，不再使用“知识卡/卡片”文案与结果组件。
- 优化入口页信息结构，明确“读取视频 → 提取文稿与总结 → 打开视频资料”的流程。
- 解析完成并得到已保存的 note id 后，自动导航到 `/library/detail?note=...`。
- 复用现有单条视频详情页的原视频播放器、完整文稿、摘要笔记、行动计划与提问能力。
- 无法获得结果 id 时保留明确的完成态和手动进入资料库入口，避免死页。

## Capabilities

### New Capabilities

- `single-link-video-import-flow`: 定义单条链接作为视频导入流程、完成后进入统一视频详情页以及异常回退行为。

### Modified Capabilities

无。

## Impact

- 前端 `/extract` 页面、页面 CSS Module 和提取完成后的客户端路由。
- 复用现有 `ExtractionContext` 与 `/library/detail`，不新增后端接口、数据库字段或播放器实现。
