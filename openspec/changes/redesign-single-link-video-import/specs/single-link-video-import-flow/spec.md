## ADDED Requirements

### Requirement: 单条解析作为视频导入流程
系统 SHALL 将 `/extract` 表达为单条视频导入入口，并 SHALL NOT 在该入口将解析结果表达为知识卡或渲染卡片结果。

#### Scenario: 用户打开单条解析
- **WHEN** 用户进入 `/extract`
- **THEN** 页面展示链接输入和“读取视频、提取文稿与总结、打开视频资料”的流程
- **AND** 页面不展示知识卡生成说明

### Requirement: 完成后进入统一视频详情
系统 SHALL 在本页发起的单条解析完成并保存后自动进入对应视频详情页，且 SHALL 使用保存结果的 note id 定位该视频。

#### Scenario: 单条视频解析成功
- **WHEN** 本页提交的解析任务返回有效 note id
- **THEN** 系统导航到 `/library/detail?note=<id>`
- **AND** 详情页展示该视频的原视频播放器和已提取资料

#### Scenario: 页面挂载时存在旧结果
- **WHEN** 用户打开 `/extract` 时全局上下文保留上一次解析结果
- **THEN** 页面不因旧结果自动跳转

#### Scenario: 完成结果缺少 note id
- **WHEN** 解析完成但没有可用于详情页的 note id
- **THEN** 页面展示明确的完成提示
- **AND** 页面提供前往视频资料库的操作

#### Scenario: 详情页读取单条导入视频
- **WHEN** 用户进入单条解析保存的视频详情
- **THEN** 系统使用已保存的视频地址、作者、封面和来源信息展示原视频
- **AND** 当临时播放地址失效时，“重新读取”会向平台刷新播放地址

#### Scenario: 播放 B站 DASH 视频
- **WHEN** 单条视频来自 B站且具有合法 BVID
- **THEN** 系统使用 B站官方播放器展示原视频
- **AND** 系统不把 B站网页地址或分离的 DASH 轨道作为原生 video 地址

### Requirement: 导入过程可理解且可恢复
系统 SHALL 在处理期间展示真实进度与取消入口，并 SHALL 在失败时保留链接输入区域供用户修正后重试。

#### Scenario: 视频链接解析完成
- **WHEN** 流程已经取得原视频元数据但文稿或总结尚未完成
- **THEN** 当前页面立即展示视频标题、封面和原视频播放区域
- **AND** 页面继续执行后续处理而不提前跳转

#### Scenario: 完整文稿提取完成
- **WHEN** 语音识别已经得到完整文稿但总结或保存尚未完成
- **THEN** 当前页面立即展示完整文稿
- **AND** 页面继续展示总结与保存进度

#### Scenario: 视频正在处理
- **WHEN** 单条视频解析尚未完成
- **THEN** 页面展示当前处理步骤
- **AND** 用户可以取消当前解析

#### Scenario: 视频解析失败
- **WHEN** 解析流程返回错误
- **THEN** 页面在输入区域附近展示友好错误
- **AND** 用户可以再次手动提交链接
