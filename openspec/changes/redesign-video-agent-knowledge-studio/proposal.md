## Why

现有视频 Agent 已经具备多视频来源检索、原文引用和多种回答形态，但来源选择、对话和最终产出仍散落在同一聊天流程中，用户不容易形成“选视频—追问—沉淀结果”的稳定心智。借鉴 NotebookLM 经验证的三栏工作区，可以让知萃更像一个以个人视频资料为中心的研究桌面，同时保留知萃独有的行动计划能力。

## What Changes

- 将“AI 助手”重新命名为“知萃研伴”，并统一桌面导航、移动导航、页面标题和相关入口文案。
- 将视频 Agent 改为三栏工作区：左侧“视频”负责搜索、筛选和勾选自己的视频来源；中间“对话”继续提供基于来源的问答与可核验引用；右侧“成果”承载总结、对比、行动方案和自定义产出。
- 保留最近任务、定时摘要、快速/深度研究和按需联网查证能力，但降低它们在主界面中的视觉优先级。
- 右侧成果从已持久化的 Agent 回答中派生，能够切换历史成果、查看完整内容、复制，以及快速发起新的总结、对比或行动方案。
- 在窄屏和移动端将三栏降级为“视频 / 对话 / 成果”可切换视图，确保主要操作可触达并保留现有底部安全区。
- 增加加载、无视频、无成果、失败与处理中的完整状态，不伪造尚未生成的内容。
- 将视频面板改为搜索优先的紧凑选择器：范围筛选收进单个控件，用户通过真实复选框确认来源；显式“智能搜索”可检索标题、作者、已保存摘要和文稿，并在 AI 查询扩展失败时安全降级。
- 让桌面三栏占满客户端内容区并采用更均衡的列宽，减少大卡片、重复说明和无效留白。
- 将同线程仍在生成时的重复消息请求明确返回冲突状态，避免把忙碌状态误报为参数错误或内部错误。
