## Why

现有“视频资料”页已经覆盖抖音、B站和小红书同步、搜索、批量处理、AI 提问与本地视频，但功能分散在多个大区块和卡片网格中，用户难以像管理桌面资料库一样快速扫描、选择并处理视频。参考图提供了更适合高频资料管理的紧凑工作台范式，因此需要在不增加虚假功能的前提下重组现有能力。

## What Changes

- 将桌面端视频资料重构为以平台状态、紧凑视频列表和选中资料详情组成的工作台，使用真实已有字段和状态。
- 将平台筛选、搜索、抖音来源/排序、批量选择与处理动作集中到列表工作流中，保留现有 API 和数据隔离语义。
- 将抖音、B站和小红书资料统一为一致的列表视觉，同时根据平台实际能力条件显示操作；B站/小红书不获得不存在的抖音批量能力。
- 将 B站/小红书账号连接、同步喜欢/收藏和手动链接导入压缩为可发现的辅助能力，继续保留本机登录和 Beta 风险提示。
- 在桌面宽屏提供基于现有数据的选中资料预览；完整文案、摘要、AI 助手、行动计划和本地视频仍复用现有详情页/桌面 bridge。
- 在窄屏改为单列列表、可折叠账号能力和安全区上方的批量操作，不强行压缩桌面三栏。
- 明确排除多账号、导入历史、回收站、站内收藏、本地文件总览、相关视频、标签编辑、分页/视图切换及任何无法由现有数据支持的统计。

## Capabilities

### New Capabilities

- `video-library-reference-workspace`: 定义视频资料桌面工作台、紧凑列表、选中预览、能力感知操作及移动端自适应行为。

### Modified Capabilities

- `multi-platform-video-library-import`: 将跨平台资料的展示要求细化为统一视觉但按平台真实能力条件呈现，并把账号同步和链接导入纳入紧凑工作流。

## Impact

- 主要影响 `frontend/src/app/library/page.tsx`、`LibraryWorkspace.module.css`、`LibraryVideoCard.tsx`、`PlatformLibraryPanel.tsx` 及其局部样式。
- 复用现有 FastAPI、Electron bridge、JWT 用户隔离、同步任务和详情路由，不新增数据库表、后端接口或第三方依赖。
- 桌面端布局显著变化；Android/移动网页保留全部适用功能并采用单列响应式呈现。
