## MODIFIED Requirements

### Requirement: 视频资料页统一展示跨平台来源

视频资料页 SHALL 在不改变主导航顺序的前提下以一致的紧凑资料行展示抖音、B站和小红书资料，并 SHALL 提供平台筛选、平台归属、搜索、真实文案状态和打开完整资料的操作；页面 MUST 根据平台实际能力条件呈现选择与管理动作。

#### Scenario: 用户选择全部来源

- **WHEN** 用户在视频资料页选择“全部”
- **THEN** 可见列表包含当前用户已加载的抖音、B站和小红书资料
- **AND** 每条资料显示明确的平台归属和真实文案状态
- **AND** 页面不声称不同来源已经执行统一时间排序或统一批量处理

#### Scenario: 用户筛选小红书

- **WHEN** 用户选择“小红书”平台筛选
- **THEN** 列表只显示当前用户的小红书导入资料
- **AND** 已输入搜索关键词继续生效
- **AND** 页面只显示小红书现有详情、摘要与来源操作

#### Scenario: 移动端导入

- **WHEN** 用户在窄屏设备打开视频资料页
- **THEN** 账号兼容提示、导入输入、提交按钮、来源筛选和结果反馈保持可触控且不被底部导航遮挡
- **AND** 手动链接导入保持为可发现的备用入口
