## Context

认证链路当前在前端开发包中内嵌固定 JWT；它依赖某个用户、签名密钥和过期时间同时匹配，无法可靠代表当前本地数据库，也会把凭证写入浏览器包。卡片详情则由独立顶栏、主题选择条、卡片和问答面板叠加组成，聚光主题还通过 GSAP 修改宽度、背景和阴影并运行超过一秒的动画，影响首屏稳定性和低性能移动设备体验。

项目约束为 Next.js 16 客户端页面、FastAPI JWT、Tailwind v4 与集中式 `globals.css`；本次不新增依赖、不改变数据库表结构，并保持生产认证强制开启。

## Goals / Non-Goals

**Goals:**

- 提供可靠、可撤销、仅本地开发可用的免登录流程。
- 删除前端源码固定 Token，仍复用现有 JWT 和用户权限体系。
- 让卡片详情形成连续的“控制区 → 阅读卡片 → 内容问答”工作台。
- 提高聚光卡片的排版、信息扫描效率、焦点可见性和移动端稳定性。
- 将交互反馈限制为 200ms 内的 `transform`/`opacity`，并尊重减少动态偏好。

**Non-Goals:**

- 不允许生产环境绕过登录。
- 不取消正常登录、注册、管理员权限或用户数据隔离。
- 不重写全部九套主题，不引入新的组件库或动画库。
- 不改变卡片持久化结构和 AI 输出格式。

## Decisions

1. **后端签发开发会话，而不是前端保存固定 Token。**
   - 新增默认关闭的 `DEV_AUTH_BYPASS` 配置。
   - `python run.py` 在导入应用配置前为本地开发设置该开关；直接运行生产 uvicorn、systemd 和生产构建不会自动开启。
   - 开发会话端点只在开关开启且请求来自回环地址时工作，并从 OpenAPI 文档隐藏。
   - 端点创建或复用保留邮箱的本地管理员，通过现有 `create_access_token` 返回标准 JWT。
   - 备选方案是继续维护固定 JWT，但它无法适配密钥、用户和数据库变化，因此放弃。

2. **前端在开发包中主动获取会话。**
   - `AuthProvider` 先验证已有 Token；无效或缺失时，只有 `NODE_ENV=development` 才调用开发会话端点。
   - 登录页在开发会话完成后使用 `router.replace` 返回目标页，避免登录表单闪现和历史记录残留。
   - 若开发端点被关闭或不可达，则保留正常登录体验，不把开发便利变成认证依赖。

3. **控制区合并为单一表面。**
   - `CardRenderer` 将工作区身份、导出/来源操作和主题选择放进同一个语义控制区。
   - 去掉互相叠加的独立阴影和重复边框，保留清晰分隔与移动端 44px 点击目标。

4. **聚光卡片改为静态优先的编辑式阅读版面。**
   - 使用单一内容类型强调色、实色表面和分隔线组织标题、引文、统计、核心洞察、章节和结论。
   - 统计改为一体式数据带；章节使用连续阅读节奏而非多张小卡；可信度条使用单色填充。
   - 聚光主题移除 GSAP 计数、滚动宽度、背景色和长延迟入场动画；仅保留 CSS 的轻量焦点/按压反馈。
   - 图标优先使用项目已经安装的 Phosphor，避免同一表面混用两套图标风格。

5. **响应式以内容宽度为准。**
   - 1080px 以上保持卡片与问答双栏，问答区粘性定位；以下切换为单栏。
   - 移动端收紧外层装饰而不压缩正文行高，卡片和问答区宽度一致，禁止页面级横向溢出。

## Risks / Trade-offs

- **[开发开关误开]** → 配置默认关闭、`run.py` 才自动设置、端点限制回环地址且不暴露在 OpenAPI。
- **[首次开发会话产生本地用户]** → 使用保留邮箱，重复启动复用同一用户；不触碰真实用户数据。
- **[去除长动画后主题显得更克制]** → 通过字体层级、留白、单色强调和表面分隔提供质感，而不是依赖运动。
- **[集中 CSS 已存在历史规则]** → 新规则限定在 `.card-workspace` 和 `.hero-*` 命名空间，构建后做桌面/移动端真实验收。

## Migration Plan

1. 增加后端配置、开发用户会话服务和受限端点。
2. 更新 `run.py` 与前端认证恢复逻辑，删除固定 Token。
3. 重构卡片控制区与聚光主题组件/CSS。
4. 运行后端定向认证检查、Python 编译、Next 生产构建与 OpenSpec 严格校验。
5. 以 `DEV_AUTH_BYPASS=true` 和 `next dev` 在 8011/3003 重启，验证直接访问登录页会进入应用。

回滚时可移除开发端点与自动会话调用；生产登录流程和数据库结构无需回滚。
