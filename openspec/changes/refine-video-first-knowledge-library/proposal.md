## Why

当前“我的知识”仍以大标题和文字条目为主，视频来源缺少封面与关键状态，用户很难像浏览成熟视频资料库一样快速识别、筛选和继续阅读内容。需要把页面从宣传式知识卡片陈列改成以视频素材为主的高密度工作区，同时保留用户自己的理解与笔记。

## What Changes

- 移除占据首屏的大 Hero，改为紧凑资料库工具栏，集中呈现总量、搜索和核心操作。
- 视频知识条目展示真实 16:9 封面、平台/作者、摘要、文稿状态、知识点数量和更新时间。
- 增加“全部 / 视频 / 我的笔记”来源筛选，以及列表/缩略图浏览方式；不恢复食谱、洞察、历史、产品、计划、通用等内容类型标签。
- 桌面端使用资料列表与按需出现的概览检查器，移动端保持单列、可横向滚动控件和 44px 触控目标。
- 将主要入口明确为“导入视频”，并保留“向全部知识提问”和“新建知识卡片”。
- 扩展混合知识列表接口的展示字段，使前端可以稳定渲染视频封面与结构化元数据。

## Capabilities

### New Capabilities

- `video-first-knowledge-browsing`: 定义视频优先的资料浏览、来源筛选、视觉缩略图和桌面概览行为。

### Modified Capabilities

- `knowledge-library-workspace`: 将知识库的默认内容列表、视图切换和移动端要求细化为紧凑、视频可识别且不依赖内容类型卡片的工作区。

## Impact

- 前端：`frontend/src/app/notes/page.tsx`、知识库 CSS 模块与封面组件复用。
- API 类型：`frontend/src/lib/api.ts` 的 `KnowledgeItem`。
- 后端：`backend/app/services/knowledge_service.py` 的混合知识列表序列化。
- 不新增第三方依赖，不改变现有知识详情、个人知识 CRUD 或鉴权模型。
