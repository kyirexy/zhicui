## Why

当前主题入口只支持二元切换，桌面外观设置又与全局主题割裂；Agent 工作区虽然具备视频检索能力，但视觉语言偏重、机器人符号陈旧，且用户难以判断回答究竟经过了哪些可验证的处理。现在需要把“简洁可选的外观”和“可信、聪明的视频 Agent”收敛为一套一致体验。

## What Changes

- 将全局主题统一为“跟随系统 / 浅色 / 深色”三档，首次使用默认浅色；设置页只展示三张简洁预览，不提供复杂的配色编辑器。
- 将默认视觉改为白色和暖灰为主、浅薄荷绿少量点缀，并让网页、桌面端和移动端共享一致的主题语义。
- 用克制的品牌化 Agent 标记替换机器人头像，重整欢迎态、消息、依据、处理阶段和输入区的层级。
- 将 Agent 的服务端流程明确为问题规划、全量资料扫描、证据筛选、可选联网、答案生成和引用校验；前端只展示真实执行阶段，不展示模型内部思维。
- 强化结构化回答解析和引用校验，使异常 JSON、无效引用或外部检索失败不会破坏主答案。

## Capabilities

### New Capabilities

- `simple-global-theme`: 覆盖全局三档主题选择、浅色默认值、系统主题响应及跨客户端持久化。

### Modified Capabilities

- `desktop-appearance-preferences`: 将桌面外观选项与全局主题统一，并保留简洁的布局密度设置。
- `video-grounded-agent-workspace`: 改进 Agent 工作区的视觉、交互、真实阶段反馈、检索编排和答案校验。

## Impact

- 前端：根布局主题初始化、主题选择器、设置页、桌面壳层、Agent 组件与全局样式。
- 后端：Agent 问题规划、检索、综合、引用校验和可观察阶段数据。
- 数据：继续使用本地外观偏好与现有 Agent 消息结构；不存储视频文件，不引入破坏性数据库迁移。
- 客户端：网页、Windows 桌面端和 Android 静态资源需要同步验证。
