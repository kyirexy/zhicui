## Why

当前 Web 首页用了多个长篇说明区块重复解释产品，访问者需要滚动很久才能看到核心功能和下载入口；同时公开首页上的账号文案让“普通访客免登录”和“管理员需要登录”两种场景混在一起。需要把首页压缩成一眼可懂的核心路径，并提供低干扰但可发现的管理员入口。

## What Changes

- 将 Web 首页精简为 Hero、三个核心功能和双平台下载中心，移除重复的品牌陈述、长流程说明、问答案例与尾部重复 CTA。
- 缩短 Hero 标题和说明，只表达“整理视频、基于资料提问、保存知识或计划”。
- 用三个简短、带语义图标的核心功能项替代四步长流程，减少学习成本和页面长度。
- 公开首页顶部不再显示普通账号登录或“账号已登录”状态；已登录管理员仍显示“管理端”。
- 页脚始终提供低干扰“管理员入口”，匿名访问时进入安全登录流程并在登录成功后返回 `/admin`。
- 管理员后台继续要求管理员账号和 `is_admin` 权限，不开放匿名后台访问。

## Capabilities

### New Capabilities

- `public-web-entry-experience`: 定义精简公开首页的核心信息层级、免登录访问方式，以及安全可发现的管理员进入路径。

### Modified Capabilities

无。

## Impact

- 受影响代码：Web 营销首页及样式、营销顶部导航、营销页脚。
- 复用现有 `/admin`、`/login?redirect=/admin`、AuthGuard 与管理员权限校验，不改变后端认证 API。
- 不改变客户端下载、版本清单、普通客户端功能路由或原生 App 导航。
