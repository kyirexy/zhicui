## Why

部分长期未刷新的 Web/Android 客户端仍可能被旧 Service Worker 或旧 Next.js 页面壳困住，表现为空白页；本地开发会话在认证请求挂起时也可能无限停留在恢复状态。与此同时，视频 Agent 已具备来源检索、持久对话和自动摘要能力，但消息失败恢复、资料范围表达、证据层级和移动端交互仍不够清晰。

## What Changes

- 增加应用壳恢复兜底：停用对 HTML 与 Next 静态资源的长期 Service Worker 缓存，并清理旧缓存与旧注册。
- 为认证恢复增加明确超时、错误状态和可操作的重试/登录入口，禁止无限空白或无限加载。
- 为 Agent 消息增加结构化响应防御、失败状态、编辑后重试和复制等低噪声操作。
- 将“当前对话资料”和“下一任务资料草稿”清楚分离，主界面只保留一个资料上下文入口。
- 细分视频原文依据、外部查证与处理过程，避免笼统声称“依据已核对”。
- 将 Agent 视觉收敛到暖中性色与低饱和蓝，绿色仅用于成功或已核对状态。
- 改善移动端回答设置、触控尺寸、底部安全区、抽屉可访问状态和常驻输入体验。

## Capabilities

### New Capabilities

- `resilient-client-shell`: 定义旧缓存清理、认证恢复超时和可操作错误状态，保证 Web、桌面和 Android 不以空白页结束。
- `refined-video-agent-interactions`: 定义 Agent 的消息失败恢复、资料上下文、证据分层、输入行为和移动端交互。

## Impact

- 前端应用壳、Service Worker、认证上下文与错误边界。
- `/agent` 工作台、消息渲染器、资料抽屉、自动摘要面板及相关样式。
- 不改变现有 Agent API 的用户隔离和视频检索契约；若运行中步骤需实时更新，后续可扩展现有作业状态接口。
